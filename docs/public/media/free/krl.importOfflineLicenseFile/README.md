# Загрузить файл офлайн-лицензии (.lic)

> **Категория:** `FREE` | **ID команды:** `krl.importOfflineLicenseFile` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Удобная активация в 1 клик выбором файла лицензии .lic без необходимости копировать длинный текстовый ключ.

## ⚙️ Принцип работы
Считывает файл с расширением .lic, верифицирует контрольную сумму SHA-256 и подпись Ed25519 и сохраняет в защищенное хранилище VS Code.

## 📂 Демонстрационный стенд / Файл
- `Файл лицензии liskin-labs-license-*.lic`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'KRL: Загрузить файл офлайн-лицензии (.lic)'.
2. Выберите скачанный с портала файл .lic.
3. Появляется уведомление: 'Лицензия успешно загружена и подтверждена!'.
