# Экспорт тегов ПЛК (Siemens TIA Portal XML / TwinCAT 3 GVL / CSV)

> **Категория:** `PRO` | **ID команды:** `krl.exportPlcTags` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Мгновенная передача карты сигналов I/O из программ робота инженерам АСУ ТП, исключая ручной ввод тысяч тегов и человеческие ошибки адресации.

## ⚙️ Принцип работы
Анализирует все объявления SIGNAL и использования $IN/$OUT в проекте, рассчитывает смещения байт.бит (%I0.0, %QW2) и генерирует нативные файлы импорта для Siemens TIA Portal XML/SDF, Beckhoff TwinCAT 3 TcGVL и EPLAN CSV.

## 📂 Демонстрационный стенд / Файл
- `KRC/R1/System/$config.dat`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Экспорт тегов ПЛК'.
2. Выберите целевой формат: Siemens TIA Portal XML или Beckhoff TwinCAT 3.
3. Получите готовый файл таблицы символов для мгновенного импорта в проект контроллера.
