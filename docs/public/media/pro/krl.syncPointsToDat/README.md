# Авто-синхронизация недостающих точек и Inline Forms в .DAT

> **Категория:** `PRO` | **ID команды:** `krl.syncPointsToDat` | **Горячие клавиши:** `Alt+S`

---

## 🎯 Инженерная задача и ценность
Устранение главной проблемы ручного переноса траекторий: отсутствие объявлений координат в companion .dat файле, вызывающее ошибку компилятора KSS01412 (Имя не объявлено).

## ⚙️ Принцип работы
Сканирует AST файла .src, находит все вызовы движения (PTP, LIN, CIRC, SPTP, SLIN) и Inline-формы (PDAT_ACT, FDAT_ACT), сравнивает их с объявлениями в .dat. Недостающие точки автоматически генерируются в секции ;FOLD Auto-Synchronized Points с сохранением структуры.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/desync_demo.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте файл .src с новыми добавленными точками движения, которых еще нет в .dat.
2. Нажмите 'Alt+S' или выберите 'KRL: Синхронизировать точки с .DAT'.
3. Расширение находит недостающие координаты и бесконфликтно дописывает структуры DECL E6POS, FDAT, PDAT в companion .dat файл.
