## 🎯 Инженерная задача и ценность
Сводный просмотр всех выставленных счетов предприятия и их статусов оплаты.

## ⚙️ Принцип работы
Отображает список счетов с номерами, датами и ссылками на скачивание PDF.

## 📂 Демонстрационный стенд / Файл

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Управление счетами (B2B)'.
2. Просмотрите статус выставленных счетов.
