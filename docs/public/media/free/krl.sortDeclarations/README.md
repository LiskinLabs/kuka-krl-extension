# Автоматическая сортировка объявлений DECL по типам данных (INT, REAL, BOOL...)

> **Категория:** `FREE` | **ID команды:** `krl.sortDeclarations` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.sortDeclarations`

---

##  Инженерная задача и ценность
Наведение идеального порядка в секции объявлений: группировка переменных по типам и алфавитный порядок.

##  Принцип работы
Находит секцию деклараций в начале подпрограммы или в файле `.dat`. Группирует строки по стандарту: сначала константы `DECL CONST`, затем простые типы (`BOOL`, `INT`, `REAL`, `CHAR`), затем системные структуры (`FRAME`, `POS`, `E6POS`, `AXIS`) и пользовательские типы.

##  Демонстрационный стенд / Файл
- `demo-workspace/main.dat`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте перемешанный файл `demo-workspace/main.dat`.
2. Вызовите `KRL: Сортировать объявления переменных (Sort Declarations)`.
3. Все строки объявлений автоматически выстраиваются в аккуратные логические блоки с комментариями-разделителями типов.
