# Калибровка базы по N реперным точкам (Лазерный трекер / SVD)

> **Категория:** `PRO` | **ID команды:** `krl.calibrateBaseNPointSvd` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Прецизионная математическая привязка системы координат Base по 3..100 измеренным точкам методом наименьших квадратов (алгоритм Кабша / SVD).

## ⚙️ Принцип работы
Принимает пары координат (теоретические из CAD и фактические с робота/лазерного трекера), сингулярным разложением матрицы ковариации вычисляет ортогональную матрицу поворота R и вектор сдвига T с расчетом среднеквадратичной ошибки (RMS).

## 📂 Демонстрационный стенд / Файл
- `Таблица реперных точек оснастки`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Калибровка базы по N реперным точкам (SVD)'.
2. Вставьте координаты точек CAD и измеренных точек робота.
3. Получите результирующий фрейм BASE_DATA[N] с погрешностью RMS до 0.05 мм.
