# Проверить статус лицензии и срок действия

> **Категория:** `FREE` | **ID команды:** `krl.checkLicenseStatus` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Просмотр текущего тарифного плана (Community / Pro / Enterprise), срока действия и количества дней триала.

## ⚙️ Принцип работы
Считывает локальный криптографический сертификат лицензии и отображает всплывающую карточку статуса.

## 📂 Демонстрационный стенд / Файл
- `Любое окно редактора`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'KRL: Проверить статус лицензии'.
2. Появляется подробная информационная плашка с типом лицензии и сроком действия.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот плашки статуса
