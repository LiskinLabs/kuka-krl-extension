# Мастер калибровки техзрения Hand-Eye (9-точечная пирамида)

> **Категория:** `PRO` | **ID команды:** `krl.generateVisionCalibration` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Точная автоматическая калибровка связки камера-робот (Eye-in-Hand / Eye-to-Hand) для систем роботизированного захвата 2D/3D зрения.

## ⚙️ Принцип работы
Генерирует 9 пространственных позиций калибровочной пирамиды с матрицей Look-At поворота оптической оси в углы Эйлера KUKA (A, B, C), формирует фазы Pre-Grasp Approach и квитирование триггера камеры по EthernetKRL.

## 📂 Демонстрационный стенд / Файл
- `Программа захвата деталей`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Мастер калибровки Hand-Eye'.
2. Укажите базовую точку калибровочного поля и ориентацию камеры.
3. Расширение строит полную калибровочную траекторию с безопасным отводом манипулятора.
