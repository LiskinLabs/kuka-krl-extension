# Отправить выделенный фрагмент кода в KUKA AI Copilot

> **Категория:** `FREE` | **ID команды:** `krl.sendSelectionToChat` | **Горячие клавиши:** `Ctrl+Shift+L`

---

## 🎯 Инженерная задача и ценность
Мгновенная передача проблемного участка кода KRL нейросетевому ассистенту для аудита безопасности и автоисправления.

## ⚙️ Принцип работы
Захватывает текст выделения, метаданные активного файла и передает в контекст чата ассистента.

## 📂 Демонстрационный стенд / Файл
- `Любой файл программы с проблемным кодом`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Выделите блок кода в редакторе.
2. Нажмите 'Ctrl+Shift+L'.
3. Код вставлен в окно чата ИИ с готовым контекстом анализа.
