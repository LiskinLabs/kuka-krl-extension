# Калькулятор систем координат KRL (Frame Calculator)

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.showCalculator` | **Калькулятор фреймов KUKA** | *KRL Frame Calculator* |

## 🎯 Цель демонстрации и визуальный фокус
Удобство расчёта сложных систем координат деталей и хватов без калькулятора и ошибок в матричной математике.

## 📂 Демонстрационный файл / Окружение
- `Любой KRL проект`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Нажать `Ctrl+Shift+P` -> `KRL: Калькулятор фреймов KUKA`.
2. Открывается графическая панель расчета 6D-фреймов (`X, Y, Z, A, B, C`).
3. Ввести координаты Frame 1 и Frame 2.
4. Нажать оператор геометрического сложения `:` (Frame Multiplication) или инверсию фрейма `INV_FRAME`.
5. Показать готовый результат и кнопку `Вставить в код` или скопировать результат.
