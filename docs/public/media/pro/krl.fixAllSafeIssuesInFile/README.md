# Безопасное автоисправление (Safe Auto-Repair) с AST-защитой и Monaco Diff Review

> **Категория:** `PRO` | **ID команды:** `krl.fixAllSafeIssuesInFile` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.fixAllSafeIssuesInFile`

---

## 🎯 Инженерная задача и ценность
Устранение сотен синтаксических ошибок, рассинхронизаций FOLD-регионов и отсутствующих объявлений в 1 клик с возможностью интерактивного подтверждения каждого изменения.

## ⚙️ Принцип работы
Строит синтаксическое дерево, находит детерминированно исправимые проблемы (закрытие FOLD, выравнивание XML-метаданных INI, очистка дубликатов C_DIS, пропущенные скобки), генерирует минимальный патч и открывает встроенный редактор сравнения (Diff Review) перед записью на диск.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/diagnostics_demo.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте файл с ошибками: `demo-workspace/diagnostics_demo.src`.
2. Обратите внимание на красные подчеркивания и рассинхронизацию FOLD.
3. Нажмите `Ctrl+Shift+P` -> `KRL: Исправить все безопасные ошибки KRL в файле (с Diff Review)`.
4. Открывается Monaco Diff редактор: слева исходный битый файл, справа идеально исправленный код.
5. Нажмите зеленую кнопку `✓ Принять изменения` на панели инструментов — файл сохраняется без ошибок.
