# Развернуть все FOLD-оболочки в документе

> **Категория:** `FREE` | **ID команды:** `krl.unfoldAll` | **Горячие клавиши:** `Ctrl+K Ctrl+J`

---

## 🎯 Инженерная задача и ценность
Мгновенное открытие всего скрытого кода для глубокого полнотекстового поиска и глобального рефакторинга.

## ⚙️ Принцип работы
Раскрывает все свернутые блоки фолдов до самого глубокого уровня вложенности.

## 📂 Демонстрационный стенд / Файл
- `Свернутый файл .src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'Ctrl+K Ctrl+J'.
2. Весь скрытый код открывается для детального анализа.
