# Инженерный калькулятор фреймов KRL (Geometric Operator & Offsets)

> **Категория:** `FREE` | **ID команды:** `krl.showCalculator` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.showCalculator`

---

## 🎯 Инженерная задача и ценность
Расчет результирующих координат при перемножении фреймов через геометрический оператор двоеточия KUKA (`F_RESULT = F_BASE : F_OFFSET`).

## ⚙️ Принцип работы
Реализует матричную алгебру Эйлера KUKA (углы Z-Y-X: A, B, C). Позволяет вводить два исходных фрейма, вычисляет прямое перемножение, инверсию координат (`INV_POS`) и отображает разницу смещений.

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите `KRL: Открыть калькулятор фреймов KRL`.
2. Открывается компактная панель с полями ввода Frame 1 (X, Y, Z, A, B, C) и Frame 2.
3. Введите координаты базовой точки и смещения инструмента.
4. Нажмите кнопку `Вычислить F1 : F2` — моментально отображаются результирующие координаты с кнопкой копирования в буфер обмена в синтаксисе KRL.
