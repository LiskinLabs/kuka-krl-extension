# Включить/выключить строку автора GitLens в коде

> **Категория:** `FREE` | **ID команды:** `krl.toggleGitLensInlineBlame` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Отображение автора последнего изменения прямо в конце строки кода (кто обучил точку на смене).

## ⚙️ Принцип работы
Переключает inline-декоратор с именем автора коммита и датой изменения строки.

## 📂 Демонстрационный стенд / Файл
- `Файл под Git`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Включите строку автора GitLens.
2. В конце строк отображается имя инженера и давность изменения.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** GIF (6 сек) переключения отображения автора
