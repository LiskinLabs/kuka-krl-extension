# Все логи событий KUKA (Единый таймлайн LE + XML)

> **Категория:** `PRO` | **ID команды:** `krl.openAllEventLogs` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Мгновенное расследование причин остановов робота: объединение всех системных журналов в одну хронологическую шкалу времени с точностью до миллисекунды.

## ⚙️ Принцип работы
Одновременно декодирует бинарные логи старого формата `<LE>` и современные XML-журналы (KUKA_HMI, SmartHMI, CrossMisc, System.evt). Выполняет сортировку по времени и переводит коды KSS на 6 языков.

## 📂 Демонстрационный стенд / Файл
- `Архив KRCDiag с системными логами`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Все логи событий KUKA (Единый таймлайн)'.
2. Выберите папку или архив с логами контроллера.
3. Интерактивная временная шкала подсвечивает аварии красным цветом с готовыми подсказками по устранению.
