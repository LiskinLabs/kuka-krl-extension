# Управление лицензиями, активация триала, B2B Angebot и встроенный чат поддержки

> **Категория:** `FREE` | **ID команды:** `krl.licenseSupport` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.openTelegramChat`

---

##  Инженерная задача и ценность
Удобное управление подпиской, активация 14-дневного триала, выписка корпоративного счета и оперативная инженерная поддержка.

##  Принцип работы
Включает встроенный клиент технической поддержки прямо в VS Code (`krl.openTelegramChat`), генератор коммерческих предложений в PDF (`krl.requestCorporateInvoice`) и интерфейс активации лицензий Dodo Payments.

##  Демонстрационный стенд / Файл
- `Любой проект`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите команду `KRL: Прямой чат с инженером-разработчиком`.
2. Открывается окно чата встроенной поддержки прямо в редакторе.
3. Напишите тестовое сообщение — система отображает подтверждение доставки.
4. Вызовите `KRL: Запросить официальный B2B счет / Angebot` — моментально формируется официальный PDF с реквизитами предприятия.
