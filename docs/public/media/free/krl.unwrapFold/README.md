# Развернуть и очистить FOLD-оболочки (Распаковать)

> **Категория:** `FREE` | **ID команды:** `krl.unwrapFold` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Удаление устаревших или поврежденных служебных оболочек ;FOLD и ;ENDFOLD с сохранением полезного кода внутри.

## ⚙️ Принцип работы
Безопасно удаляет открывающие и закрывающие строки фолда, аккуратно нормализуя отступы внутреннего кода.

## 📂 Демонстрационный стенд / Файл
- `Файл с вложенными фолдами`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Поставьте курсор на строку фолда.
2. Вызовите 'KRL: Развернуть / Очистить FOLD-оболочки'.
3. Оболочка удалена, исполняемый код остался на месте.
