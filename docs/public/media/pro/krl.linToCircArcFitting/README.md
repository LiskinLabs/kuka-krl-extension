# 3D аппроксимация плотных цепочек отрезков LIN в сглаженные дуги CIRC

> **Категория:** `FREE` | **ID команды:** `krl.linToCircArcFitting` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.linToCircArcFitting`

---

##  Инженерная задача и ценность
Сглаживание движений и уменьшение размера файла: замена тысяч мелких ломаных линий LIN на гладкие дуги окружностей CIRC.

##  Принцип работы
Применяет алгоритм аппроксимации дуг по трем точкам с заданной хордовой погрешностью (Chordal Tolerance 0.1 мм). Сокращает количество строк кода в 5–10 раз и обеспечивает более плавный ход робота.

##  Демонстрационный стенд / Файл
- `demo-workspace/motion_and_splines.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Выделите цепочку мелких отрезков LIN.
2. Вызовите `KRL: Аппроксимировать полилинии LIN в дуги CIRC (3D)`.
3. Задайте допуск погрешности `0.1 мм`.
4. Блок заменяется на компактные дуговые команды CIRC с промежуточными и конечными точками.
