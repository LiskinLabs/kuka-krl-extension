# Промышленная очистка неиспользуемых переменных и мертвого кода [PRO]

> **Категория:** `PRO` | **ID команды:** `krl.cleanupUnusedVariables` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.cleanupUnusedVariables`

---

## 🎯 Инженерная задача и ценность
Освобождение энергонезависимой оперативной памяти контроллера KRC (RAM) и удаление сотен мусорных координат и переменных, оставшихся после десятков модификаций программы на производственной линии.

## ⚙️ Принцип работы
Интеллектуальный анализатор графа зависимостей с двухуровневым селектором области:
1. **Селектор области (QuickPick)**:
   - *Только активный модуль (.src / .dat)* — быстрый поиск неиспользуемых локальных переменных внутри DEF...END.
   - *Весь проект / открытый бэкап* — глобальный перекрестный поиск по всем .src, .dat, .sub и .xml файлам ячейки.
2. **Токенизатор сложных структур**: корректно обрабатывает вложенные структуры `{...}` (`E6POS`, `FDAT`, `FRAME`), массивы `[...]` и строковые литералы без ложных срабатываний на полях `Y 20.0`, `Z 30.0`.
3. **Многоуровневая защита внешних интерфейсов**:
   - *Public Module Guard*: защита модулей с `DEFDAT ... PUBLIC`.
   - *Background Task (sps.sub) Protection*: перекрестный контроль сигналов и переменных фонового Submit.
   - *EthernetKRL (EKI) XML Protection*: защита переменных, привязанных к XML-тегам камер и ПЛК.
   - *Иммунитет системных файлов*: абсолютный запрет на удаление из `$config.dat`, `$machine.dat`, `$robcor.dat`.
4. **Безопасный режим по умолчанию**: переменные по умолчанию комментируются (`; DECL ...`), что позволяет оператору мгновенно восстановить их прямо на пульте SmartPAD без потери обученных координат.
5. **Monaco Diff Review**: просмотр изменений в нативном редакторе сравнения до записи на диск.

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/dead_code_demo.src` и парный `.dat` файл.
2. Обратите внимание на серые приглушенные строки неиспользуемых переменных.
3. Вызовите `KRL: Удалить неиспользуемые переменные и мертвый код`.
4. В селекторе выберите область действия (например, 'Только активный модуль').
5. Плагин выводит список найденных сиротских переменных с возможностью выбора.
6. Подтвердите операцию — `.dat` файл очищен или безопасно закомментирован, память контроллера оптимизирована.
