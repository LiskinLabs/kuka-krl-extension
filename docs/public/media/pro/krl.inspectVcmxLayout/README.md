# Инспектор 3D-ячейки KUKA.Sim / Visual Components (.vcmx / layout.rsc)

> **Категория:** `PRO` | **ID команды:** `krl.inspectVcmxLayout` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Мгновенная инспекция структуры цифрового двойника и симуляционной ячейки .vcmx без необходимости запуска тяжелой CAD/CAM системы.

## ⚙️ Принцип работы
Двухуровневый парсер читает бинарный контейнер layout.rsc внутри .vcmx, извлекает узлы rSimNode, манипуляторы, булевы сигналы взаимодействия и технологические подпрограммы ProgramData.

## 📂 Демонстрационный стенд / Файл
- `Архив ячейки симуляции .vcmx`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите команду 'KRL: Инспектор 3D-ячейки KUKA.Sim (.vcmx)'.
2. Выберите файл симуляции .vcmx.
3. Получите наглядную иерархическую карточку: роботы, инструмент, сенсоры, сигналы обмена и длины технологических траекторий.
