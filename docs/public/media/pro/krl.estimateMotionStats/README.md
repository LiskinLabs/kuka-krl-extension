# Анализатор динамики движения, Vorlaufstopp (падение $ADVANCE) и расчёт цикла

> **Категория:** `PRO` | **ID команды:** `krl.estimateMotionStats` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.estimateMotionStats`

---

## 🎯 Инженерная задача и ценность
Оптимизация времени цикла роботизированной ячейки: обнаружение скрытых микро-остановок манипулятора, вызванных неаккуратной работой с сигналами I/O.

## ⚙️ Принцип работы
Анализирует команды движения `PTP`, `LIN`, `CIRC`, проверяет наличие ключевых слов приближения (`C_PTP`, `C_DIS`), ищет операторы `$OUT[...] = ...` и `WAIT FOR` без предваряющего `CONTINUE`, вычисляет штраф времени Vorlaufstopp (250–450 мс на каждую точку) и суммарную экономию секунд.

## 📂 Демонстрационный стенд / Файл

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/motion_and_splines.src`.
2. Вызовите `KRL: Оценить статистику движения и остановки упреждающего чтения (Advance Run)`.
3. В отчёте выводится: общее расстояние траектории, расчётное время цикла, количество точек с непрерывным сглаживанием и список 4 строк, где $ADVANCE падает до 0.
4. Покажите рекомендацию плагина: `Используйте TRIGGER WHEN PATH или вставьте CONTINUE перед $OUT[12]=TRUE`.
