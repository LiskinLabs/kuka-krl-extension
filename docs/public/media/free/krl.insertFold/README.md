# Вставить стандартный FOLD-регион KUKA

> **Категория:** `FREE` | **ID команды:** `krl.insertFold` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Быстрое создание пользовательского блока группировки кода, корректно распознаваемого пультом SmartPAD.

## ⚙️ Принцип работы
Вставляет шаблонную структуру ;FOLD <Имя> ... ;ENDFOLD с автоматическим сохранением отступов.

## 📂 Демонстрационный стенд / Файл
- `Любой файл программы .src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Выделите строки кода.
2. Вызовите 'KRL: Вставить FOLD-регион'.
3. Введите название блока — выделенный код обернут в аккуратный фолд.
