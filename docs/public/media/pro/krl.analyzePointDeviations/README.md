# Анализ отклонения точек от соседей (Излом и смещение шва)

> **Категория:** `PRO` | **ID команды:** `krl.analyzePointDeviations` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Автоматический аудит геометрической плавности траектории: выявление случайных резких перегибов, переворотов кисти и отклонений шва.

## ⚙️ Принцип работы
Рассчитывает кривизну пространственной полилинии, углы между соседними векторами скорости и предупреждает об участках, где угол излома превышает технологический допуск.

## 📂 Демонстрационный стенд / Файл
- `Плотная траектория лазерной резки или фрезерования`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Анализ отклонения точек от соседей'.
2. Ознакомьтесь с графиком и списком точек с аномальными углами излома (> 30°).
3. Быстрый переход к проблемному участку в один клик.
