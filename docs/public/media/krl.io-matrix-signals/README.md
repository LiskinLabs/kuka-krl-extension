# Матрица сигналов I/O, переименование и детектор коллизий

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.showIoMatrix` | **Матрица сигналов I/O и детектор коллизий** | *Visual I/O Signal Matrix & Overlap Detector* |
| `krl.refreshIOView` | **Обновить панель I/O** | *Refresh I/O View* |
| `krl.renameSignal` | **Переименовать сигнал (алиас)** | *Rename Signal (Set Alias)* |

## 🎯 Цель демонстрации и визуальный фокус
Наглядный контроль всех сигналов связи робота с ПЛК, датчиками и пневмоостровами.

## 📂 Демонстрационный файл / Окружение
- `demo-workspace/$config.dat`
- `demo-workspace/signals_and_timers.src`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть `demo-workspace/$config.dat`.
2. `Ctrl+Shift+P` -> `KRL: Матрица сигналов I/O и детектор коллизий` (krl.showIoMatrix).
3. Открывается интерактивная таблица всех дискретных и аналоговых входов/выходов ($IN / $OUT) с индикацией занятых битов и детектом двойного назначения.
4. Нажать `KRL: Переименовать сигнал (алиас)` на сигнале `$OUT[10]` -> ввести новое имя `diGripperClosed` -> сигнал обновляется во всём проекте.
5. Нажать `KRL: Обновить панель I/O` -> боковая панель KRL I/O Explorer синхронизируется.
