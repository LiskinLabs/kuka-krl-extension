# Обновить проводник парка роботов (Fleet Explorer)

> **Категория:** `FREE` | **ID команды:** `krl.fleetExplorer.refresh` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Быстрое повторное сканирование рабочей папки с десятками бэкапов роботов завода.

## ⚙️ Принцип работы
Рекурсивно обновляет дерево роботов в сайдбаре с определением серийных номеров и версий KSS.

## 📂 Демонстрационный стенд / Файл
- `Панель Fleet Explorer`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите кнопку обновления в шапке Fleet Explorer.
2. Список роботов актуализирован за доли секунды.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот панели Fleet Explorer
- **Рекомендуемые целевые файлы в эту папку:**
