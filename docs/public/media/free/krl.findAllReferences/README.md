# Поиск всех ссылок и использований символов в проекте (Find All References)

> **Категория:** `FREE` | **ID команды:** `krl.findAllReferences` | **Горячие клавиши:** `Shift+F12`

---

## 🎯 Инженерная задача и ценность
Оценка влияния изменений: выяснить, в каких именно местах проекта используется выбранная глобальная переменная или сигнал.

## ⚙️ Принцип работы
Строит дерево перекрестных ссылок по всему воркспейсу и выводит интерактивную панель со списком всех вызовов с группировкой по файлам и номерам строк.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/cell.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. В `demo-workspace/cell.src` установите курсор на переменную `$IN[10]`.
2. Нажмите `Shift+F12` (или кликните ПКМ -> `Найти все ссылки`).
3. Справа раскрывается панель со списком всех 6 мест использования сигнала в разных файлах проекта.
4. Кликайте по элементам списка — код в центральном редакторе плавно прокручивается к нужным строкам.
