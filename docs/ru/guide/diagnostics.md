# Диагностика промышленной безопасности

<span class="badge pro">Pro Функция</span>

Обнаружение синтаксических сбоев, аварийных скоростей и рисков физических столкновений до загрузки программы в реальный контроллер KUKA KRC.

## 1. Баланс структурных блоков
Предотвращает фатальные ошибки незакрытых тегов `IF/ENDIF`, `FOR/ENDFOR`, `LOOP/ENDLOOP`.

## 2. Инициализация $TOOL и $BASE
Предупреждает о вызове команд движения (`PTP`, `LIN`, `CIRC`) без предварительной установки активного инструмента и базы.

## 3. Блокировщик скрытых ошибок (Кириллица)
Компилятор KRC падает без указания причины, если в исполняемом коде присутствуют невидимые символы кириллицы. Наш инспектор подсвечивает их в реальном времени.
