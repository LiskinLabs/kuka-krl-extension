# CAM-постпроцессор: разделение гигантских траекторий на модули с сохранением FOLD

> **Категория:** `FREE` | **ID команды:** `krl.splitProgram` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.splitProgram`

---

##  Инженерная задача и ценность
Обход аппаратного ограничения памяти контроллера KSS на максимальный размер программы (допустимо до 30 000 строк в одном файле).

##  Принцип работы
Принимает гигантские траектории фрезеровки или 3D-печати из CAD/CAM систем (SprutCAM, PowerMill, Mastercam), разделяет файл на логические модули по N тысяч строк с генерацией головной программы вызова.

##  Демонстрационный стенд / Файл
- `Большой CAM-файл фрезеровки`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте большую траекторию движения.
2. Вызовите `KRL: Разделить большую CAM-программу на подпрограммы`.
3. Задайте лимит: `5000 строк на модуль`.
4. Плагин генерирует файлы `Part_1.src`, `Part_2.src`... и головной диспетчер с последовательным вызовом.
