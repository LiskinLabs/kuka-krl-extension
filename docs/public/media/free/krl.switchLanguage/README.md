# Мгновенное переключение языка интерфейса (RU, EN, DE, TR, ES, IT)

> **Категория:** `FREE` | **ID команды:** `krl.switchLanguage` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.switchLanguage`

---

##  Инженерная задача и ценность
Удобство интернациональных команд: мгновенная смена языка всех меню, отчетов, диагностики и документации без перезагрузки VS Code.

##  Принцип работы
Динамически обновляет словарь i18n расширения на лету, моментально меняя локализацию команд в палитре, дерева проводника, центра управления и всплывающих подсказок.

##  Демонстрационный стенд / Файл
- `Любой проект`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите `KRL: Сменить язык интерфейса (Switch Interface Language)`.
2. В выпадающем списке выберите `Deutsch (German)` или `Türkçe (Turkish)`.
3. Все надписи, меню и подсказки мгновенно переключаются на выбранный язык без перезапуска редактора.
