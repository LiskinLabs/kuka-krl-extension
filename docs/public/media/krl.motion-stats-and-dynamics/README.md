# Аналитика траекторий, время цикла и детектор сингулярностей

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.estimateMotionStats` | **Длина траектории и статистика движений/сварки** | *Trajectory Path Length & Motion Stats* |
| `krl.runDynamicAnalysis` | **Динамический анализ траектории и сингулярностей** | *Run Dynamic Trajectory & Singularity Analysis* |

## 🎯 Цель демонстрации и визуальный фокус
Промышленный аудит перед загрузкой в реальный робот: экономия времени цикла и защита от аварий.

## 📂 Демонстрационный файл / Окружение
- `demo-workspace/welding_process.src`
- `demo-workspace/welding_process.dat`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть `demo-workspace/welding_process.src`.
2. Запустить `KRL: Длина траектории и статистика движений/сварки` (krl.estimateMotionStats).
3. В сплывающем окне или вебвью отображается подробная статистика: длина холостых перемещений, длина рабочих швов сварки, расчетное время цикла в секундах.
4. Запустить `KRL: Динамический анализ траектории и сингулярностей` (krl.runDynamicAnalysis).
5. Анализатор проверяет переход через ось A5 (A4/A6 singularity) и предупреждает о риске останова робота.
