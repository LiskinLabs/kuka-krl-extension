# Активировать Pro-лицензию (Онлайн-ключ)

> **Категория:** `FREE` | **ID команды:** `krl.activateLicense` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Быстрая онлайн-активация расширения по серийному ключу лицензии.

## ⚙️ Принцип работы
Отправляет запрос валидации ключа на защищенный шлюз Cloudflare Workers и сохраняет лицензионный токен в локальном защищенном хранилище.

## 📂 Демонстрационный стенд / Файл
- `Диалог ввода ключа`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Активировать Pro-лицензию'.
2. Введите купленный лицензионный ключ.
3. Появляется уведомление: 'Лицензия Pro успешно активирована'.
