# Единый центр управления KUKA Control Center (Дашборд)

> **Категория:** `FREE` | **ID команды:** `krl.openControlCenter` | **Горячие клавиши:** `Ctrl+Alt+K`

---

## 🎯 Инженерная задача и ценность
Центральный рабочий пульт инженера: мониторинг состояния проекта, быстрый доступ к калькулятору фреймов, матрице сигналов, настройкам KSS и документации.

## ⚙️ Принцип работы
Запускает интерактивный Webview в стиле современных промышленных интерфейсов. Выводит статус лицензии, текущую версию компилятора, счетчики обнаруженных ошибок, кнопки генерации отчетов и прямую связь с поддержкой.

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите иконку KUKA в статус-баре или горячие клавиши `Ctrl+Alt+K`.
2. Открывается дашборд KUKA Control Center.
3. Продемонстрируйте интерактивные карточки: статус синтаксического анализа, переключатель языка интерфейса, быстрый запуск калькулятора фреймов и матрицы I/O.
4. Переключите тему оформления (Dark Obsidian / Light Daylight).
