# SCADA Live Bridge: реальная телеметрия робота (6 осей, моменты, TCP, KSS Alarms)

> **Категория:** `PRO` | **ID команды:** `krl.live.openDashboard` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.live.openDashboard`

---

## 🎯 Инженерная задача и ценность
Прямой онлайн-мониторинг реального контроллера KUKA на заводе по сети Ethernet: живые углы осей A1-A6, нагрузки приводов, координаты TCP и поток аварий.

## ⚙️ Принцип работы
Устанавливает сокет-соединение с контроллером через CrossComm/EthernetKRL/WinGate (порт 49000/7000), считывает переменные `$AXIS_ACT`, `$TORQUE_AXIS_ACT`, `$POS_ACT`, `$IN`, `$OUT` с частотой до 50 Гц и отображает аппаратные индикаторы в реальном времени.

## 📂 Демонстрационный стенд / Файл
- `Контроллер KRC4/KRC5 в сети или локальный симулятор`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите `KRL: Открыть панель онлайн-телеметрии SCADA Live Bridge`.
2. Нажмите кнопку `Подключиться к роботу` (введите IP адрес 192.168.x.x).
3. Интерфейс оживает: 6 круговых шкал осей A1-A6 отображают живые градусы с цветовой индикацией приближения к концевикам $SOFTN/$SOFTP.
4. Отображаются крутящие моменты в Нм, живая позиция инструмента TCP (X, Y, Z, A, B, C) и лента сообщений KSS с мгновенным переводом на русский язык.
