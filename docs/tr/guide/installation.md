# Kurulum ve Ayarlar Kılavuzu

KUKA KRL Professional eklentisini kurmak ve yapılandırmak için hızlı başlangıç kılavuzu.

## 1. VS Code Marketplace Üzerinden Kurulum
1. VS Code'u açın.
2. Eklentiler görünümüne gidin (`Ctrl + Shift + X`).
3. `KUKA KRL Professional` aramasını yapın.
4. **Install** düğmesine tıklayın.

## 2. VSIX Dosyası İle Kurulum (Çevrimdışı Kurulum)
1. `kuka-krl-extension-1.8.7.vsix` dosyasını indirin.
2. VS Code'da Eklentiler panelinin sağ üst köşesindeki `...` menüsünü tıklayın.
3. **Install from VSIX...** seçeneğini seçip dosyayı belirleyin.

## 3. KUKA Teması Seçimi
1. `Ctrl + K`, ardından `Ctrl + T` tuşlarına basın.
2. 6 özel temadan birini seçin: **Industrial Dark**, **WorkVisual Dark**, **WorkVisual Light**, **Midnight OLED**, **Blueprint**, **Industrial Light**.

## 4. Pro Lisansı Etkinleştirme
1. **KUKA Control Center**'ı açın.
2. **Enter License Key** düğmesine tıklayın.
3. Dodo Payments lisans anahtarınızı yapıştırın ve **Activate** düğmesine basın.

## 5. Telegram Mühendislik Desteği
Teknik destek için doğrudan VS Code içindeki yerleşik destek panelini kullanabilirsiniz.

Entegre Telegram destek şebekesi üzerinden doğrudan kıdemli mühendis desteği, merkezi otomatik KUKA Filo Yedekleme Merkezi ve OEM markalı müşteri kabul raporlarını (Ford, Renault, TOGG, Saint-Gobain) içerir.
