# Сравнить строку с предыдущей ревизией коммита (Diff)

> **Категория:** `FREE` | **ID команды:** `krl.diffWithPrevious` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Мгновенное понимание: кто, когда и как изменил конкретную точку траектории или инструкцию.

## ⚙️ Принцип работы
Сравнивает текущее состояние строки с предыдущим коммитом в репозитории Git и открывает построчный diff.

## 📂 Демонстрационный стенд / Файл
- `Файл в репозитории Git`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Поставьте курсор на измененную строку и вызовите команду.
2. Открывается окно сравнения с предыдущей версией.
