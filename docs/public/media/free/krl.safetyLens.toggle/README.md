# Переключить KRL Inline Safety Lens (Оверлей безопасности)

> **Категория:** `FREE` | **ID команды:** `krl.safetyLens.toggle` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Отображение рисков безопасности (дрейф $BASE/$TOOL, пропуски BRAKE) прямо над строками кода.

## ⚙️ Принцип работы
Включает и выключает прозрачные inline-линзы безопасности над критическими инструкциями движения.

## 📂 Демонстрационный стенд / Файл
- `Программа с неопределенным инструментом`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Переключить Inline Safety Lens'.
2. Над строками движения появляются бейджи с текущими активными номерами Tool и Base.
