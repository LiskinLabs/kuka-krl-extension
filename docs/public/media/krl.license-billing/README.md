# Корпоративное лицензирование, офлайн Air-Gapped и B2B счета

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.activateLicense` | **Активировать Pro-лицензию** | *Activate Pro License* |
| `krl.deactivateLicense` | **Деактивировать Pro-лицензию** | *Deactivate Pro License* |
| `krl.checkLicenseStatus` | **Проверить статус лицензии** | *Check License Status* |
| `krl.startTrial` | **Активировать 14-дневный бесплатный Pro триал** | *Start 14-Day Pro Free Trial* |
| `krl.activateOfflineLicense` | **Активировать Air-Gapped офлайн-лицензию** | *Activate Air-Gapped Offline License* |
| `krl.copyMachineFingerprint` | **Скопировать Hardware ID (отпечаток ПК)** | *Copy Machine Fingerprint (Hardware ID)* |
| `krl.openCustomerPortal` | **Личный кабинет и инвойсы (Dodo Payments)** | *Open Customer Portal & Invoices (Dodo Payments)* |
| `krl.requestCorporateInvoice` | **Запросить официальный B2B счет / Angebot (PDF & EU VAT 0%)** | *Request Corporate Quote / Invoice (Angebot)* |
| `krl.downloadLatestInvoice` | **Скачать последний официальный B2B инвойс Dodo (PDF)** | *Download Latest Dodo Corporate Invoice (PDF)* |

## 🎯 Цель демонстрации и визуальный фокус
Прозрачность и удобство для промышленных предприятий и корпоративных заказчиков.

## 📂 Демонстрационный файл / Окружение
- `KUKA Control Center / Панель лицензирования`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Вызвать `KRL: Активировать 14-дневный бесплатный Pro триал` -> мгновенное включение Pro-функционала в один клик без ввода кредитной карты.
2. Вызвать `KRL: Проверить статус лицензии` -> окно со статусом Pro, датой окончания и фичами.
3. Вызвать `KRL: Скопировать Hardware ID (отпечаток ПК)` -> копирование криптографического HWID для изолированных цеховых ноутбуков без интернета.
4. Вызвать `KRL: Запросить официальный B2B счет / Angebot` -> генерация коммерческого предложения для юридических лиц с нулевым НДС ЕС.
