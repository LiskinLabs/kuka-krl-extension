# Анализатор автомобильных стандартов Volkswagen / Audi Group (VKRC / VASS 26)

> **Категория:** `PRO` | **ID команды:** `krl.checkVkrcStatus` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.checkVkrcStatus`

---

## 🎯 Инженерная задача и ценность
Строгий аудит кода кузовных производств концерна Volkswagen Group (Audi, Porsche, VW, Skoda, SEAT) на соответствие стандарту VASS 26.

## ⚙️ Принцип работы
Сканирует программы шагов (Folge), подпрограммы (Up) и макросы (Makro 0..999). Проверяет обязательное ограничение скорости `VE=0%` на вызовах `SPSMAKRO`, подтверждение блокировок `A23=AUS`, формат масок `&PARAM EDITMASK` и выдает рекомендации по адаптации.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/cell.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте проект автомобильной линии или файл стандарта VKRC.
2. Вызовите команду `KRL: Проверить соответствие стандарту VKRC / VASS 26`.
3. Инспектор формирует сводный отчёт: статус соответствия правилам VASS, перечень найденных макросов и отклонения от стандарта кузовного цеха.
