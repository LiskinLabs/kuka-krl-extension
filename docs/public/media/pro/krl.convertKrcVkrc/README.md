# Конвертер программ KRC <-> Volkswagen VKRC (Folge / UP + FK)

> **Категория:** `PRO` | **ID команды:** `krl.convertKrcVkrc` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Двусторонняя конвертация программ между стандартным KUKA KRC и заводским автомобильным стандартом Volkswagen VKRC (VASS).

## ⚙️ Принцип работы
Транслирует линейные модули KRL в структуры Folge / UP с обратным пересчетом абсолютных углов E6AXIS через решение прямой задачи кинематики в декартовы точки E6POS и наоборот.

## 📂 Демонстрационный стенд / Файл
- `Программа KRC или VW Folge`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Конвертировать программу KRC <-> VKRC'.
2. Выберите направление конвертации.
3. Получите полностью структурированную программу со всеми необходимыми макрошагами и технологическими точками.
