# Обзорная таблица активных калибровок инструмента $TOOL и базы $BASE

> **Категория:** `FREE` | **ID команды:** `krl.toolBaseOverview` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.toolBaseOverview`

---

##  Инженерная задача и ценность
Быстрая проверка используемых в программе фреймов инструмента и базы детали.

##  Принцип работы
Анализирует вызовы `BAS(#TOOL, n)` и `BAS(#BASE, m)`, находит их числовые значения в `$config.dat` (`TOOL_DATA[n]`, `BASE_DATA[m]`) и выводит удобную сводную таблицу калибровок.

##  Демонстрационный стенд / Файл
- `demo-workspace/cell.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/cell.src`.
2. Вызовите `KRL: Показать обзор калибровок Tool и Base`.
3. Открывается таблица со всеми номерами инструментов, их геометрическими вылетами (TCP X, Y, Z) и массами нагрузки.
