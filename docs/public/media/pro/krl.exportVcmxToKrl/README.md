# Экспорт траекторий KUKA.Sim VCMX в KRL (.src / .dat)

> **Категория:** `PRO` | **ID команды:** `krl.exportVcmxToKrl` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Прямой перенос траекторий симуляции из цифрового двойника в готовые к исполнению программы KUKA KRL для реального контроллера.

## ⚙️ Принцип работы
Конвертирует узлы ProgramData (LinMotion, PtpMotion, SetSignal, WaitSignal, Delay) в синтаксически корректные пары файлов .src и companion .dat с промышленными заголовками и FOLD-структурами.

## 📂 Демонстрационный стенд / Файл
- `3D-проект .vcmx с обученной траекторией`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите команду 'KRL: Экспорт траекторий KUKA.Sim в KRL'.
2. Выберите целевой компонент робота из ячейки.
3. Получите сгенерированные файлы .src и .dat с идеальным форматированием.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** GIF (10 сек) генерации кода из модели
