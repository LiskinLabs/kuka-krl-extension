---

## 🎯 Инженерная задача и ценность
Быстрое подтверждение предложенного исправления без использования мыши.

## ⚙️ Принцип работы
Применяет diff-патч к текущему документу и закрывает окно предпросмотра.

## 📂 Демонстрационный стенд / Файл
- `Окно Monaco Diff Review`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. В окне сравнения нажмите 'Ctrl+Enter'.
2. Изменения применены к исходному файлу.
