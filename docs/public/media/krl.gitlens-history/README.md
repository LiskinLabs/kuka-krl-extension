# Промышленный GitLens: таймлайн точек, Diff ревизий и авторы строк

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.diffWithPrevious` | **Сравнить строку с предыдущей ревизией коммита (Diff)** | *Compare Line with Previous Commit Revision (Diff)* |
| `krl.compareTwoRevisions` | **Сравнить две любые ревизии файла (Diff)** | *Compare Any Two Commit Revisions (Diff)* |
| `krl.viewFileHistory` | **История изменений файла и сравнение ревизий (Git)** | *View KRL File History & Compare Revisions* |
| `krl.viewLineHistory` | **История изменений выделенных строк (git log -L)** | *View Selected Lines History (git log -L)* |
| `krl.viewGitGraph` | **Открыть граф ревизий KRL и таймлайн точек** | *Open KRL Revision Graph & Point Timeline* |
| `krl.showLineBlameDetails` | **Детали автора строки KRL (Git Blame)** | *Show KRL Line Git Blame Details* |
| `krl.toggleGitLensInlineBlame` | **Включить/выключить строку автора GitLens в коде** | *Toggle GitLens Inline Blame Annotations* |
| `krl.copyCommitMessage` | **Скопировать сообщение коммита** | *Copy Commit Message* |

## 🎯 Цель демонстрации и визуальный фокус
Кто, когда и почему изменил координату точки сварки или логику захвата детали.

## 📂 Демонстрационный файл / Окружение
- `Любой файл под версионным контролем Git`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть файл под Git-контролем.
2. Показать полупрозрачную аннотацию в конце строки: автор коммита, время назад, сообщение.
3. Вызвать `KRL: Сравнить строку с предыдущей ревизией коммита (Diff)` -> открывается сплит-дифф конкретной координаты.
4. Вызвать `KRL: Открыть граф ревизий KRL и таймлайн точек` -> визуальный граф коммитов с историей движения робота.
5. Вызвать `KRL: История изменений выделенных строк (git log -L)` -> показ точечной истории выделенного блока.
