# Инженерные отчеты качества и протокол приёмки (Abnahmeprotokoll)

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.generateReport` | **Сформировать отчёт качества кода** | *Generate Acceptance Report* |
| `krl.generateAcceptanceReport` | **Сформировать протокол приёмки робота (Abnahmeprotokoll)** | *Generate Robot Acceptance Protocol (Abnahmeprotokoll)* |

## 🎯 Цель демонстрации и визуальный фокус
Готовая инженерная документация для сдачи проекта заказчику за один клик.

## 📂 Демонстрационный файл / Окружение
- `Любой KRL проект`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Вызвать `KRL: Сформировать отчёт качества кода` -> генерация сводного отчёта по стандартам чистоты кода, количеству строк, соблюдению соглашений об именах.
2. Вызвать `KRL: Сформировать протокол приёмки робота (Abnahmeprotokoll)` -> формируется официальный акт приёмки с реквизитами ячейки, данными робота, списком контрольных проверок безопасности по стандарту ISO 10218-1/2.
3. Показать кнопку экспорта в PDF для передачи заказчику.

## 📹 Рекомендуемый формат захвата
- **Формат:** Скриншот готового PDF/HTML отчёта и обзорный GIF (7-9 сек)
- **Рекомендуемые имена итоговых файлов в эту папку:**
  - `acceptance_report_pdf.png`
  - `quality_report_webview.gif`

> *Примечание: После создания скриншота, GIF или видео сохраняйте готовые файлы прямо в эту папку. Они будут автоматически синхронизироваться с сайтом документации и витриной маркетплейса.*
