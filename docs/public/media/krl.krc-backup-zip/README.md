# Работа с реальными бэкапами KRC: ZIP Explorer, Live Mount и Diff

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.openBackupZipExplorer` | **Открыть и исследовать архив бэкапа KRC (.zip)** | *Open & Inspect KRC Backup Archive (.zip)* |
| `krl.mountBackupZipAsProject` | **Открыть бэкап .ZIP как проект (с авто-сохранением в архив)** | *Open KRC Backup .ZIP as Live Project (Auto-Sync to Archive)* |
| `krl.syncAllToBackupZip` | **Синхронизировать все изменения проекта с .ZIP архивом** | *Sync All Workspace Changes to Original Backup .ZIP* |
| `krl.compareKrcBackup` | **Сравнить файлы и координаты с бэкапом KRC (.zip)** | *Compare File & Point Deltas with KRC Backup Archive (.zip)* |
| `krl.exportBackupZip` | **Выгрузить бэкап проекта KRL (.zip)** | *Export Project KRL Backup (.zip)* |

## 🎯 Цель демонстрации и визуальный фокус
Уникальная фича расширения: работа с роботом напрямую через архив бэкапа без сотен распакованных папок.

## 📂 Демонстрационный файл / Окружение
- `Любой архив бэкапа KRC4/KRC5 (.zip) или demo-workspace`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Нажать `Ctrl+Shift+P` -> `KRL: Открыть бэкап .ZIP как проект (с авто-сохранением в архив)`.
2. Выбрать `.zip` архив бэкапа робота -> бэкап монтируется во временную изолированную среду.
3. Отредактировать траекторию или точку -> вызвать `KRL: Синхронизировать все изменения проекта с .ZIP архивом` -> изменения упаковываются обратно в оригинальный ZIP.
4. Вызвать `KRL: Сравнить файлы и координаты с бэкапом KRC (.zip)` -> открывается мощнейший Delta Inspector, показывающий какие точки были смещены оператором на пульте SmartPAD.
5. Вызвать `KRL: Выгрузить бэкап проекта KRL (.zip)` -> скачивание готового к заливке архива.
