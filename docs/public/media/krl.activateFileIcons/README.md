# Фирменные иконки файлов KRL и темы робототехники

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.activateFileIcons` | **Включить иконки файлов KRL (.src, .dat, .sub, .kfd)** | *Activate KRL File Icons (.src, .dat, .sub, .kfd)* |

## 🎯 Цель демонстрации и визуальный фокус
Эстетичный внешний вид дерева файлов проекта: мгновенная узнаваемость файлов KUKA в проводнике.

## 📂 Демонстрационный файл / Окружение
- `Боковое дерево проводника VS Code (Explorer)`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть проводник VS Code с папкой `demo-workspace`.
2. `Ctrl+Shift+P` -> `KRL: Включить иконки файлов KRL (.src, .dat, .sub, .kfd)`.
3. Показать крупным планом список файлов: оранжевые иконки `.src` (манипулятор/шестерня), синие/зеленые `.dat` (базы данных), системные `.sub`, XML схемы EKI.

## 📹 Рекомендуемый формат захвата
- **Формат:** Скриншот высокого разрешения (PNG 1920x1080) или GIF
- **Рекомендуемые имена итоговых файлов в эту папку:**
  - `krl_file_icons_explorer.png`
  - `krl_icons_activate.gif`

> *Примечание: После создания скриншота, GIF или видео сохраняйте готовые файлы прямо в эту папку. Они будут автоматически синхронизироваться с сайтом документации и витриной маркетплейса.*
