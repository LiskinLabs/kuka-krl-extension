| :--- | :--- | :--- |

## 🎯 Цель демонстрации и визуальный фокус
Главная витрина продукта — современный, технологичный дашборд промышленного уровня.

## 📂 Демонстрационный файл / Окружение
- `Любой KRL проект`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Нажать на иконку Liskin Labs в статус-баре или вызвать `KRL: Открыть KUKA Control Center`.
2. Открывается интерактивный Webview-центр управления: статус лицензии, версия KSS, сводка ошибок линтера, быстрые кнопки запуска калькулятора, матрицы I/O, отчётов и поддержки.
3. Продемонстрировать интерактивность кнопок и переключение вкладок.
