# Бинарный инспектор системных журналов KUKA Event Log (.evt / KSS Diagnostics)

> **Категория:** `PRO` | **ID команды:** `krl.openEventLog` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.openEventLog`

---

##  Инженерная задача и ценность
Декодирование бинарных архивов сообщений контроллера SmartHMI/KSS (.evt) без необходимости физического подключения к роботу.

##  Принцип работы
Парсит структуру `LE (Little-Endian)` двоичных файлов `KUKA_HMI.evt`, `CrossMisc.evt`, `System.evt`. Преобразует шестнадцатеричные смещения в читаемые временные метки с миллисекундами, сопоставляет коды KSS с локализованной базой решений (Cause & Remedy) и позволяет фильтровать события по важности (Alarm, State, Quit).

##  Демонстрационный стенд / Файл
- `Архив бэкапа с папкой Log или файл .evt`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите `KRL: Открыть и декодировать журнал событий KUKA (.evt)`.
2. Выберите тестовый файл журнала событий `.evt`.
3. Открывается таблица событий с точным временем, доменом (KSS, HMI, BUS) и описанием ошибки.
4. Кликните на ошибку (например, `KSS01442`) — справа раскрывается экспертная подсказка с вероятной физической причиной и инструкцией по сбросу аварии.
5. Покажите экспорт отфильтрованных событий в CSV.
