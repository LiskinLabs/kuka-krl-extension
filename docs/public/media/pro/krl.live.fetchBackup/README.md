# Автономный горячий бэкап с KRC (.zip по сети)

> **Категория:** `PRO` | **ID команды:** `krl.live.fetchBackup` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Создание и скачивание полного архива бэкапа прямо с работающего робота по сети в один клик без подхода к пульту SmartPAD.

## ⚙️ Принцип работы
Отправляет безопасный сервисный запрос на контроллер, инициирует создание снапшота программ и скачивает упакованный .zip архив на рабочий компьютер.

## 📂 Демонстрационный стенд / Файл
- `Подключенный контроллер`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'KRL: Автономный горячий бэкап с KRC'.
2. Наблюдайте прогресс-бар выгрузки файлов.
3. Архив робота сохранен на компьютере и готов к анализу.
