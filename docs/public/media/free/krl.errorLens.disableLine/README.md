# Error Lens: Подавить предупреждение на текущей строке

> **Категория:** `FREE` | **ID команды:** `krl.errorLens.disableLine` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Быстрое добавление комментария подавления линтера для нестандартных решений на линии.

## ⚙️ Принцип работы
Вставляет в конец строки комментарий ; krl-ignore для отключения диагностического правила.

## 📂 Демонстрационный стенд / Файл
- `Строка с предупреждением`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите команду на строке с предупреждением.
2. Предупреждение на этой строке скрыто.
