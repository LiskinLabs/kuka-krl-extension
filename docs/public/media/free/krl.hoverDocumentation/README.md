# Всплывающая документация и статус чтения/записи системных переменных KSS

> **Категория:** `FREE` | **ID команды:** `krl.hoverDocumentation` | **Горячие клавиши:** `Наведение курсора мыши`

---

##  Инженерная задача и ценность
Мгновенная справка по любой инструкции или переменной без необходимости открывать бумажные PDF-мануалы KUKA.

##  Принцип работы
При наведении курсора мыши на любое слово в коде открывается карточка документации: назначение, допустимый диапазон значений, тип данных и индикатор прав доступа (Только чтение / Чтение и запись).

##  Демонстрационный стенд / Файл
- `demo-workspace/cell.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/cell.src`.
2. Наведите курсор мыши на `$MODE_OP`.
3. Всплывает всплывающее окно с описанием: режим работы контроллера (#T1, #T2, #AUT, #EXT), тип ENUM и пометка `Read-Only`.
4. Наведите курсор на имя пользовательской подпрограммы — отображаются её параметры и файл декларации.

##  Рекомендуемый визуальный формат
- **Формат:** Короткий анимированный GIF (7 сек) или Скриншот (PNG)
- **Рекомендуемые целевые файлы в эту папку:**
  - `hover_docs_demo.gif`
  - `hover_docs_screen.png`
