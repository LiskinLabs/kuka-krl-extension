# Прозрачное монтирование архивов бэкапов (.zip / KRCDiag) как рабочего пространства

> **Категория:** `PRO` | **ID команды:** `krl.mountBackupZipAsProject` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.mountBackupZipAsProject`

---

## 🎯 Инженерная задача и ценность
Мгновенное открытие и редактирование заводских архивов робота без предварительной ручной распаковки архиватором.

## ⚙️ Принцип работы
Использует виртуальную файловую систему в памяти. Монтирует внутреннее дерево `KRC/R1/...` как отдельное чистое рабочее пространство VS Code, сохраняя оригинальную структуру каталогов.

## 📂 Демонстрационный стенд / Файл
- `Любой архив `Archive.zip` или `KRCDiag.zip``

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Кликните правой кнопкой мыши по файлу `.zip` в проводнике или вызовите команду `KRL: Монтировать архив бэкапа ZIP как рабочий проект`.
2. Через 1 секунду проект смонтирован: в дереве проводника открыта только папка `KRC/R1/Program` без мусорных системных логов.
3. Файлы `.src` и `.dat` полноценно открываются с подсветкой, автодополнением и линтингом.
