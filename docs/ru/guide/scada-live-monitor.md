# Промышленный Live Controller Monitor реального времени

Онлайн-телеметрия и прямое подключение к промышленным роботам KUKA KRC2, KRC4 и KRC5.

---

## Обзор

**Live Controller Monitor** (`krl.live.connect`, `krl.live.openDashboard`) устанавливает прямое соединение по промышленному Ethernet между VS Code и контроллерами роботов KUKA (`KR C2`, `KR C4`, `KR C5` / `KR C5 micro` / `KR C5-2`) под управлением `KSS 5.4–8.7`, `VSS (VKRC) 8.3–8.7` и `iiQKA.OS2 9.0–9.4`.

Инструмент выводит телеметрию цеха, нагрузки на двигатели 6 осей, декартовы координаты TCP, матрицу до 4096 сигналов ввода-вывода и ленту системных сообщений SmartPAD прямо в среду разработки.

---

## Архитектура и официальные порты KUKA

Live-монитор выбирает нативный транспорт под поколение контроллера без установки WorkVisual или сторонних DLL (данные сверены с таблицами портов `GC464` и `GC855`):

1. **WCF OnlineServices (TCP 49002)**: Системная служба `smartHMI` для `KR C4` / `KR C5` (`KSS 8.x` / `VSS`). Используется для диагностики, чтения структуры проекта, compile gate и управления бэкапами.
2. **iiQKA gRPC / SmartHMI API (TCP 443, авторизация Ory Kratos)**: Нативный клиент для `iiQKA.OS2 9.0–9.4` с поддержкой переподключения и удалённой проверки сборки.
3. **OPC UA Server (TCP 4840)**: Диагностический probe для проверки доступности OPC UA интерфейса контроллера (`KSS 8.x` / `iiQKA.OS2`).
4. **KUKAVARPROXY / C3Bridge (TCP 7000)**: Циклический опрос переменных реального времени (`$AXIS_ACT`, `$POS_ACT`, `$IN`/`$OUT`, `$TORQMON`) на `KR C2` и `KR C4`.
5. **Ethernet KRL (EKI, TCP/UDP 54600–54615) и RSI (`49152` и выше / порт `60809` в iiQKA.OS2)**: Настраиваемые порты пользовательского обмена XML/JSON и коррекции траектории в реальном времени.

> Пароли и учётные данные контроллеров хранятся локально для каждого хоста в системном хранилище **VS Code SecretStorage** без зашитых учётных данных по умолчанию.

## Ключевые возможности

### 1. Шестиосевая шкала телеметрии и моментов осей
* **Отслеживание положения осей**: Чтение `$AXIS_ACT` и `$AXIS_MOT` для осей A1..A6 в реальном времени.
* **Моменты двигателей и скорости**: Динамические полосы нагрузки двигателей с сопоставлением пределам `$TORQMON`, выявляющие механические перегрузки до срабатывания аварийного останова.
* **Контроль пределов хода**: Цветовые индикаторы приближения осей к программным концевым выключателям (`$SOFTP_END`, `$SOFTN_END`).

### 2. Декартовы координаты TCP и активные рамки
* **Текущее положение TCP**: Отображение `$POS_ACT` с координатами X, Y, Z (мм) и углами Эйлера A, B, C.
* **Статус систем координат**: Номер и параметры активного инструмента `$TOOL` и базы детали `$BASE`.

### 3. Динамическая матрица I/O на 4096 каналов и Watch SVG
* **Сетка на 4096 каналов + фильтр CFG**: Матрица дискретных входов `$IN[1..4096]` и выходов `$OUT[1..4096]` с фильтром **CFG**, автоматически сопоставляющим физически сконфигурированные сигналы из `KrcIoSignals.xml` (WorkVisual) и описаний SmartPAD `UserTexts.kxr` / `$config.dat`.
* **Флаги и таймеры**: Состояние системных флагов `$FLAG[1..1024]` и таймеров `$TIMER[1..64]`.
* **Watch-графики (SVG)**: Построение живых мини-трендов выбранных переменных в процессе цикла и подсветка фронтов рукопожатий с ПЛК.

### 4. Поток аварий SmartPAD, 7-point Health Check и Compile Gate
* **Хронологическая лента сообщений**: Лента аварий, предупреждений и диалоговых запросов контроллера с раздельным журналом до 200 записей (`krl.live.openMessages`).
* **Вкладка Health (7 проверок)**: Контроль состояния контроллера, режимов (`T1`/`T2`/`AUT`/`EXT`), готовности приводов, безопасных стопов, состояния SPS, подключения и версии ПО.
* **Compile Gate и Zero-Config Discovery / Cross-Subnet Scout**: Автоматическое обнаружение роботов в локальной сети, поиск в смежных подсетях (`Cross-Subnet Scout`) и проверка компиляции (`SynchronizeMirror -> AnalyzeAllKrlFiles -> GetModuleInfos`) с безопасным повтором при занятости шины контроллера.
* **Субтитры перевода (`KSS_LOOKUP`)**: Устранение языкового барьера при международной пусконаладке — под кодами контроллера отображаются описания на русском и английском языках.

### 5. Горячее скачивание бэкапа по Ethernet
* **Архивация без останова ячейки**: Скачивание чистого архива бэкапа `.zip` напрямую с контроллера через Ethernet (SMB `KRC` share или транспорт контроллера).
* **Непрерывность производства**: Выгрузка выполняется на стороне контроллера без снижения скорости чтения телеметрии.

## Команды и горячие клавиши

| Команда | Идентификатор | Описание |
|---|---|---|
| KUKA KRL: Подключиться к роботу KUKA | `krl.live.connect` | Мастер подключения к контроллеру (WCF / gRPC / KVP / Scout) |
| KUKA KRL: Открыть панель Live Monitor | `krl.live.openDashboard` | Запуск панели телеметрии, Watch-графиков и вкладки Health |
| KUKA KRL: Открыть сообщения SmartPAD | `krl.live.openMessages` | Полный журнал сообщений контроллера с поиском и фильтрами |
| KUKA KRL: Скачать бэкап с контроллера | `krl.live.fetchBackup` | Горячая выгрузка `.zip` бэкапа с робота |

## Актуально для v1.9.25–1.9.26

- **Zero-Config Discovery и Cross-Subnet Scout**: Автопоиск доступных контроллеров KRC / iiQKA в цеховой сети и смежных VLAN без ручного перебора IP.
- **Фильтр I/O `CFG` + `UserTexts.kxr` + OPC UA `4840` Probe**: Подсветка только реально сконфигурированных каналов из `KrcIoSignals.xml` с подписями SmartPAD, Watch SVG-трендами и проверкой порта `4840`.
- **7-check Health Tab и Compile Gate с повторами**: Единый индикатор готовности ячейки и устойчивый прогон `SynchronizeMirror -> AnalyzeAllKrlFiles -> GetModuleInfos` для `KSS 9.3+` (явные маски `*.src` / `*.dat`).
- **Защита учётных данных (`SecretStorage`)**: Все пароли контроллеров хранятся изолированно в VS Code SecretStorage без дефолтных значений в коде.
