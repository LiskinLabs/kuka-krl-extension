# Настроить путь к KUKA WorkVisual на компьютере

> **Категория:** `FREE` | **ID команды:** `krl.configureWorkVisualPath` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Интеграция с установленной средой KUKA WorkVisual для автоматического извлечения 3D-моделей и каталогов KOP.

## ⚙️ Принцип работы
Открывает файловый проводник для выбора пути к WorkVisual.exe и сохраняет его в настройки расширения.

## 📂 Демонстрационный стенд / Файл
- `Файловый проводник`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Настроить путь к KUKA WorkVisual'.
2. Выберите путь к установленному WorkVisual на диске C:.
3. Путь сохранен, расширение автоматически подхватывает официальные каталоги.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот выбора пути
- **Рекомендуемые целевые файлы в эту папку:**
  - `wvs_path_screen.png`

---
*Примечание: Сохраняйте созданные скриншоты, GIF-анимации и видео прямо в эту папку. Они автоматически подхватываются документацией и витриной маркетплейса.*
