# Настроить путь и параметры виртуального контроллера

> **Категория:** `FREE` | **ID команды:** `krl.configureVirtualController` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Конфигурация сетевого адреса (IP) и рабочего каталога виртуальной машины KSS.

## ⚙️ Принцип работы
Открывает диалог ввода IP-адреса, порта и пути к общей папке программ для сохранения в settings.json.

## 📂 Демонстрационный стенд / Файл
- `Окно настроек VS Code`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Настроить путь к виртуальному контроллеру...'.
2. Введите IP и порт виртуальной машины.
3. Настройки успешно сохранены.
