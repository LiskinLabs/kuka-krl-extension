# Деактивировать Pro-лицензию на текущем ПК

> **Категория:** `FREE` | **ID команды:** `krl.deactivateLicense` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Освобождение слота лицензии для переноса на другой рабочий ноутбук или ПК инженера.

## ⚙️ Принцип работы
Отзывает активный токен на сервере лицензий и очищает локальные данные авторизации.

## 📂 Демонстрационный стенд / Файл
- `Диалог подтверждения деактивации`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Деактивировать Pro-лицензию'.
2. Подтвердите отзыв — лицензия освобождена и готова к переносу.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот диалога подтверждения
