# Управление подпиской и поддержка (Отмена / Возврат)

> **Категория:** `FREE` | **ID команды:** `krl.manageSubscription` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Прозрачное управление подпиской с возможностью изменения тарифного плана в один клик.

## ⚙️ Принцип работы
Предоставляет меню действий: продление, отмена подписки, запрос возврата или смена периода оплаты.

## 📂 Демонстрационный стенд / Файл
- `Меню управления подпиской`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Управление подпиской'.
2. Выберите необходимое действие из списка.
