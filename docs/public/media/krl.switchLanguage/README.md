# Мультиязычный интерфейс (6 локализаций)

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.switchLanguage` | **Сменить язык интерфейса** | *Switch Interface Language* |

## 🎯 Цель демонстрации и визуальный фокус
Полноценная локализация на родные языки международных инженеров-робототехников.

## 📂 Демонстрационный файл / Окружение
- `Любой KRL документ / Command Palette`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Нажать `Ctrl+Shift+P` -> `KRL: Сменить язык интерфейса` (krl.switchLanguage).
2. Появляется QuickPick меню со списком языков: English, Русский, Deutsch, Español, Italiano, Türkçe.
3. Выбрать Deutsch или Русский -> показать, как все команды, уведомления и статус-бар мгновенно обновляются на выбранном языке без перезапуска IDE.
