# Установка и настройка KUKA KRL Professional

Руководство по быстрой установке и началу работы с расширением.

## 1. Установка из VS Code Marketplace
1. Откройте VS Code.
2. Перейдите во вкладку расширений (`Ctrl + Shift + X`).
3. Введите в поиске `KUKA KRL Professional`.
4. Нажмите **Install**.

## 2. Установка из VSIX-файла (Offline Installation)
1. Скачайте файл `kuka-krl-extension-1.8.8.vsix`.
2. В VS Code выберите меню `...` в правом верхнем углу панели Extensions.
3. Нажмите **Install from VSIX...** и выберите файл.

## 3. Выбор темы оформления KUKA
1. Нажмите `Ctrl + K`, затем `Ctrl + T`.
2. Выберите одну из 6 фирменных тем: **Industrial Dark**, **WorkVisual Dark**, **WorkVisual Light**, **Midnight OLED**, **Blueprint**, **Industrial Light**.

## 4. Активация Pro Лицензии
1. Откройте **KUKA Control Center** нажатием на иконку KUKA в Activity Bar или по команде `KRL: Open Control Center`.
2. Нажмите кнопку **Enter License Key**.
3. Вставьте ваш лицензионный ключ от Dodo Payments и нажмите **Activate**.

## 5. Поддержка в Telegram
По всем вопросам вы можете связаться с инженером поддержки через встроенный чат в VS Code или через официальный шлюз поддержки в Telegram.

### Почему бессрочная лицензия Pro Lifetime стоит $699 разово, а Enterprise Site — $1,499 в год?
- **Pro Lifetime ($699 разово)** даёт бессрочную лицензию на **1 рабочую станцию (1 ПК)** навсегда без каких-либо подписок, скрытых списаний и с пожизненными обновлениями. Поддерживает выпуск персонального криптографического Air-Gapped сертификата для работы в изолированных цеховых сетях без интернета.
- **Enterprise Site ($1,499/год)** — это **безлимитная корпоративная лицензия на целый производственный завод**. Все компьютеры и пульты предприятия работают по единой лицензии без ограничений по числу активаций (~$8/мес на рабочее место при 20 специалистах). В тариф включена прямая приоритетная поддержка от разработчика через Telegram-шлюз, облачный автоматический KUKA Fleet Backup Hub для ячеек завода и брендированные протоколы приёмки для автопроизводителей (Ford, Renault, TOGG, Saint-Gobain).
