# Копировать конфигурацию MCP (Cursor, Claude, Antigravity)

> **Категория:** `FREE` | **ID команды:** `krl.mcp.copyConfig` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Подключение возможностей промышленного расширения KUKA KRL к современным ИИ-ассистентам в один клик.

## ⚙️ Принцип работы
Генерирует готовый JSON-блок конфигурации Model Context Protocol для локального моста 127.0.0.1 с токеном авторизации.

## 📂 Демонстрационный стенд / Файл
- `Буфер обмена`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Копировать конфигурацию MCP'.
2. Выберите ИИ-клиент (Cursor / Claude Desktop / Antigravity).
3. Конфигурация скопирована и готова к вставке в настройки ассистента.
