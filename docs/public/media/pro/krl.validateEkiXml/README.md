# Валидатор и линтер XML-пакетов Ethernet KRL (EKI) с проверкой типов

> **Категория:** `PRO` | **ID команды:** `krl.validateEkiXml` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.validateEkiXml`

---

## 🎯 Инженерная задача и ценность
Предотвращение зависания сетевого стека EthernetKRL при обмене данными с системами технического зрения (Cognex, Keyence) и ПЛК по TCP/IP.

## ⚙️ Принцип работы
Анализирует конфигурационный XML-файл EKI (`<ETHERNETKRL>`), проверяет корректность тегов `<RECEIVE>`, `<SEND>`, буферов памяти, портов подключения и типов данных элементов (INT, REAL, STRING, BOOL), выявляя скрытые ошибки спецификации KUKA.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/eki_demo.xml`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте конфигурационный файл `demo-workspace/eki_demo.xml`.
2. Вызовите `KRL: Валидировать файл конфигурации Ethernet KRL (EKI XML)`.
3. Линтер мгновенно подсвечивает ошибки структуры XML, недопустимые типы данных и несоответствия размеров буфера в панели Problems.
4. Покажите всплывающую подсказку с рекомендацией по исправлению структуры тегов.
