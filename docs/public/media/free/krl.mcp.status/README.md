# Показать статус локального моста MCP

> **Категория:** `FREE` | **ID команды:** `krl.mcp.status` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Контроль состояния и активности локального ИИ-шлюза Model Context Protocol.

## ⚙️ Принцип работы
Опрашивает локальный loopback сервер расширения и выводит активный порт, статус авторизации и количество подключенных сессий.

## 📂 Демонстрационный стенд / Файл
- `Строка состояния / Инфопанель`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'KRL: Показать статус локального моста MCP'.
2. Отображается порт (напр. 63443) и статус готовности к обработке запросов от ИИ.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот статуса MCP
