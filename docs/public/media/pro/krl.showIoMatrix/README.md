# Визуальная матрица сигналов ввода-вывода I/O и коллизий битов ($IN, $OUT, $FLAG)

> **Категория:** `PRO` | **ID команды:** `krl.showIoMatrix` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.showIoMatrix`

---

## 🎯 Инженерная задача и ценность
Инспекция всех задействованных сигналов дискретного ввода-вывода контроллера с защитой от одновременной записи нескольких процессов в один бит.

## ⚙️ Принцип работы
Сканирует файлы `$config.dat`, `.sub`, `.src` на обращения к массивам `$IN[...]`, `$OUT[...]`, `$FLAG[...]`. Строит интерактивную сетку сигналов 1..4096, подсвечивает используемые биты цветом, отображает мнемонические имена из WorkVisual и выявляет перекрытия (bit collisions).

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/$config.dat`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/$config.dat` или любой проект.
2. Вызовите команду `KRL: Показать матрицу сигналов I/O`.
3. Открывается высокотехнологичная сетка сигналов с вкладками $OUT, $IN, $FLAG.
4. Покажите переключение между блоками по 64 бита (1-64, 65-128...).
5. Наведите курсор на задействованный бит — всплывает карточка с именем сигнала, местом в коде и статусом чтения/записи.
6. Покажите фильтр поиска сигнала по имени (например, `Gripper_Close`).
