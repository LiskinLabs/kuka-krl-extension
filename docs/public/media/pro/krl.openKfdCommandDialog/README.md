# Вставка и редактирование KFD Inline-форм (Каталог команд)

> **Категория:** `PRO` | **ID команды:** `krl.openKfdCommandDialog` | **Горячие клавиши:** `Ctrl+K Ctrl+F`

---

## 🎯 Инженерная задача и ценность
Создание и редактирование технологических Inline-форм KUKA на компьютере с визуальным диалогом, идентичным интерфейсу пульта SmartPAD.

## ⚙️ Принцип работы
Использует движок парсинга KFD-скриптов для рендеринга интерактивных форм команд (движение, логика выходов, таймеры, технологии). Формирует валидные закрытые ;FOLD структуры с XML-метаданными.

## 📂 Демонстрационный стенд / Файл
- `Любой файл программы .src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'Ctrl+K Ctrl+F'.
2. В появившемся диалоге выберите тип команды (PTP, LIN, OUT, WAIT).
3. Задайте скорость, сглаживание и нажмите 'Вставить' — в код вставляется 100% валидный фолд KUKA.
