# Интеграция Model Context Protocol (MCP) и ИИ-ассистентов

Подключение внешних сред ИИ к онлайн-телеметрии промышленных роботов и статической диагностике проектов.

---

## Обзор

**Model Context Protocol (MCP)** — открытый промышленный протокол взаимодействия искусственного интеллекта со средами разработки и оборудованием.

Расширение KUKA KRL содержит **встроенный локальный сервер MCP Bridge** на `127.0.0.1`. Он связывает современные среды ИИ-разработки (**Cursor, Google Antigravity, Claude Code CLI, Windsurf**) напрямую с кодом проекта KRL, системой AST-диагностики и телеметрией реального контроллера робота.

---

## Инструменты MCP

Внешние ИИ-агенты получают доступ к специализированным промышленным инструментам:

| Имя инструмента | Область | Назначение |
|---|---|---|
| `krl_live_telemetry` | Оборудование | Чтение углов осей, координат TCP, активных систем координат, режима работы и аварий с реального робота |
| `krl_workspace_diagnostics` | Проект | Полный аудит файлов `.src`, `.dat`, `.sub` на предмет синтаксических ошибок, незакрытых FOLD и сбросов Vorlaufstopp |
| `krl_safe_auto_repair` | Код | Детерминированное исправление расхождений фолдов, добавление BRAKE и устранение зависаний STEP 0 |
| `krl_system_variable_spec` | База знаний | Справка по типам данных, физическим единицам и пределам массивов 957+ системных переменных KSS |
| `krl_alarm_lookup` | Диагностика | Расшифровка кодов ошибок контроллера (например, `KSS00203`, `KSS01442`) на 6 языках |

## Подключение клиентов ИИ

### 1. Автоматическая настройка в Cursor
При запуске в редакторе Cursor расширение автоматически регистрирует сервер MCP через `vscode.cursor.mcp.registerServer` без необходимости ручной правки настроек.

### 2. Экспорт JSON-конфигурации в 1 клик
Используйте команду `KUKA KRL: Copy MCP Configuration` (`Ctrl+Shift+P`) для копирования готового блока конфигурации под Claude Desktop, Cursor, Antigravity и Windsurf.

### 3. Открытые репозитории
* **Автономный сервер**: [LiskinLabs/kuka-krl-mcp](https://github.com/LiskinLabs/kuka-krl-mcp) (Лицензия MIT)
