# Подключиться к онлайн-контроллеру KRC (SCADA Bridge)

> **Категория:** `PRO` | **ID команды:** `krl.live.connect` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Установление прямого сетевого соединения с реальным роботом KUKA на заводе для телеметрии и онлайн-диагностики.

## ⚙️ Принцип работы
Подключается по промышленным сетевым портам (CrossComm, WCF, WinGate) к контроллеру KRC2/KRC4/KRC5 и начинает безопасный опрос телеметрии.

## 📂 Демонстрационный стенд / Файл
- `Онлайн контроллер в локальной сети`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'KRL: Подключиться к контроллеру'.
2. Введите IP-адрес робота (например, 192.168.11.120).
3. Индикатор в строке состояния загорается зеленым: 'KRC CONNECTED'.
