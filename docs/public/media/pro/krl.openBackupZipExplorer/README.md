# Открыть и исследовать архив бэкапа KRC (.zip / .tar / .wvs)

> **Категория:** `PRO` | **ID команды:** `krl.openBackupZipExplorer` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Быстрый просмотр и навигация по архиву бэкапа робота без его извлечения на диск.

## ⚙️ Принцип работы
Монтирует виртуальное дерево файлов архива в сайдбаре VS Code, позволяя мгновенно находить программы, файлы конфигурации и логи.

## 📂 Демонстрационный стенд / Файл
- `Любой бэкап робота .zip`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Выберите бэкап в меню 'Открыть архив бэкапа'.
2. В проводнике открывается структурированное дерево R1, System, Steu.
3. Кликните на файл для мгновенного чтения.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот или короткий GIF (6 сек)
- **Рекомендуемые целевые файлы в эту папку:**
  - `backup_explorer_demo.gif`
  - `backup_explorer_screen.png`
