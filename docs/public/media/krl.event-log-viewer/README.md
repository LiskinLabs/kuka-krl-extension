# Декодер логов событий KUKA (.EVT) и единый таймлайн

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.openEventLog` | **Декодер и просмотр логов KUKA (.evt)** | *Decode & View KUKA Event Log (.evt)* |
| `krl.openAllEventLogs` | **Все логи событий KUKA (Единый таймлайн)** | *Open All KUKA Event Logs (Unified Timeline)* |
| `krl.viewRobotImage` | **Просмотр изображения модели робота KUKA (WorkVisual)** | *View KUKA Robot Model Image (WorkVisual)* |

## 🎯 Цель демонстрации и визуальный фокус
Мгновенное чтение бинарных логов аварий робота прямо в редакторе без внешних тяжелых утилит.

## 📂 Демонстрационный файл / Окружение
- `Файлы KUKA Event Log (*.evt, KrcDiag)`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Кликнуть по файлу `.evt` в проводнике или вызвать `KRL: Декодер и просмотр логов KUKA (.evt)`.
2. Открывается красивый графический вьювер событий: хронологический список аварий, предупреждений, состояний безопасности, сообщений SmartPAD.
3. Вызвать `KRL: Все логи событий KUKA (Единый таймлайн)` -> объединение логов контроллера и приводов в единый синхронный таймлайн.
4. Вызвать `KRL: Просмотр изображения модели робота KUKA (WorkVisual)` -> рендер модели робота.
