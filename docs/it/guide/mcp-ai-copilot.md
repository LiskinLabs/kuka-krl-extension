# Integrazione AI con Model Context Protocol (MCP)

Integrazione diretta di assistenti di intelligenza artificiale con la telemetria del controllore e la diagnostica statica di progetto KRL.

---

## Panoramica

L'estensione include un **server bridge locale MCP** su `127.0.0.1` compatibile con **Cursor, Google Antigravity, Claude Code e Windsurf**, consentendo di interrogare telemetria in tempo reale (`krl_live_telemetry`), eseguire diagnostica del workspace (`krl_workspace_diagnostics`) e consultare 957+ variabili di sistema KSS.
