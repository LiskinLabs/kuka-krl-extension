# Пакетный 3D/6D сдвиг и вращение точек траектории в файлах .dat

> **Категория:** `PRO` | **ID команды:** `krl.batchShiftPoints` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.batchShiftPoints`

---

## 🎯 Инженерная задача и ценность
Пакетное смещение траектории при физическом переносе оснастки или стола в цеху без необходимости заново переобучать сотни точек на SmartPAD.

## ⚙️ Принцип работы
Применяет матричное преобразование ко всем точкам типа E6POS/POS/FRAME в выделенном диапазоне. Позволяет задать линейное смещение dX, dY, dZ (в мм) и поворот dA, dB, dC (в градусах) с предпросмотром результата.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/welding_process.dat`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Выделите массив точек в `.dat` файле.
2. Вызовите `KRL: Пакетный сдвиг и поворот точек (Batch Shift)`.
3. В модальном интерфейсе введите смещение: `dX = 0`, `dY = 50.0`, `dZ = -10.0`.
4. Нажмите применить — все координаты выделенных точек пересчитываются синхронно с сохранением форматирования.
