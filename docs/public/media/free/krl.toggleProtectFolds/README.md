# Переключить режим защиты фолдов (Protect Folds)

> **Категория:** `FREE` | **ID команды:** `krl.toggleProtectFolds` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Защита от случайного случайного редактирования служебных строк KUKA Inline Forms при разработке.

## ⚙️ Принцип работы
Переводит заголовочные строки ;FOLD и ;ENDFOLD в режим защиты от случайной перезаписи.

## 📂 Демонстрационный стенд / Файл
- `Файл программы`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Включите режим 'Protect Folds'.
2. Служебные метаданные защищены от случайного повреждения.
