# Сравнение бэкапов SmartPAD (.zip) и 3D-дельта координат (Delta Math)

> **Категория:** `PRO` | **ID команды:** `krl.compareKrcBackup` | **Горячие клавиши:** `Ctrl+Alt+B`

---

##  Инженерная задача и ценность
Выявление несанкционированных изменений ночной смены: мгновенное сравнение двух архивов бэкапов робота с расчетом смещения обученных точек в миллиметрах.

##  Принцип работы
Принимает два .zip архива (или папки), сравнивает структуру файлов, выявляет добавленные/удаленные подпрограммы, а для совпадающих `.dat` файлов вычисляет евклидово смещение по формуле sqrt(dx^2+dy^2+dz^2) и угловые отклонения по осям A, B, C.

##  Демонстрационный стенд / Файл
- `demo-workspace/backup_delta_demo.dat`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите `Ctrl+Alt+B` или вызовите `KRL: Сравнить бэкапы SmartPAD (.zip)`.
2. В модальном окне выберите эталонный бэкап (Reference) и актуальный бэкап (Current).
3. Открывается двухколоночный инспектор: дерево измененных файлов и таблица геометрических дельт точек.
4. Точки со смещением > 2 мм подсвечиваются оранжевым/красным бейджем `Δ = +4.82 mm`.
5. Кликните на точку — открывается Side-by-Side сравнение строк `.dat` с подсвеченными числами.
