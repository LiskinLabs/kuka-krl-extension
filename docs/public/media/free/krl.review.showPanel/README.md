# Показать панель рецензирования изменений (KRL Review)

> **Категория:** `FREE` | **ID команды:** `krl.review.showPanel` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Единая панель контроля качества для пошагового принятия или отклонения всех автоматических исправлений.

## ⚙️ Принцип работы
Отображает список всех модифицированных файлов с бейджами количества правок и кнопками массового подтверждения.

## 📂 Демонстрационный стенд / Файл
- `Пакет отредактированных файлов`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте панель 'KRL Review'.
2. Просмотрите список измененных файлов и дельту правок.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот панели KRL Review
- **Рекомендуемые целевые файлы в эту папку:**
  - `review_panel_screen.png`
