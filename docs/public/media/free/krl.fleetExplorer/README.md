# Обозреватель роботов парка и интеграция с изображениями WorkVisual

> **Категория:** `FREE` | **ID команды:** `krl.fleetExplorer` | **Горячие клавиши:** `Боковая панель KRL Explorer`

---

##  Инженерная задача и ценность
Инвентаризация и быстрый доступ ко всем роботам предприятия в едином дереве проводника.

##  Принцип работы
Автоматически обнаруживает конфигурации контроллеров в проекте, отображает паспортную модель робота (например, `KR 210 R2700 prime`), серийный номер и показывает технические иллюстрации кинематики из базы WorkVisual.

##  Демонстрационный стенд / Файл
- `demo-workspace/$machine.dat`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте боковую панель KUKA KRL Explorer.
2. Раскройте вкладку `KUKA Robot Fleet`.
3. Отображаются карточки обнаруженных контроллеров с иконками моделей.
4. Кликните на модель робота — открывается паспорт кинематики с изображением манипулятора и предельными углами осей.
