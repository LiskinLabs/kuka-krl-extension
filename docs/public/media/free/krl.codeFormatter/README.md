# Индустриальный форматтер кода KRL (3 пробела KUKA и выравнивание матриц)

> **Категория:** `FREE` | **ID команды:** `krl.codeFormatter` | **Горячие клавиши:** `Shift+Alt+F`

---

##  Инженерная задача и ценность
Приведение программ к официальному стандарту оформления KUKA: отступы в 3 пробела для вложенных блоков и идеальное выравнивание знаков равенства в .dat файлах.

##  Принцип работы
Форматирует документ по AST-структуре: выравнивает вложенность IF, LOOP, FOR, FOLD с шагом в 3 пробела, приводит ключевые слова к верхнему регистру (UPPERCASE) и форматирует числовые матрицы координат в аккуратные читаемые таблицы.

##  Демонстрационный стенд / Файл
- `demo-workspace/formatting_demo.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте неряшливо оформленный файл `demo-workspace/formatting_demo.src`.
2. Нажмите стандартную комбинацию форматирования `Shift+Alt+F`.
3. За долю секунды весь код выравнивается: ровные отступы 3 пробела, ключевые слова в верхнем регистре, аккуратные FOLD-структуры.
