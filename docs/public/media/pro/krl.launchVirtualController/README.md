# Запуск виртуального контроллера (VM Sandbox) [PRO]

> **Категория:** `PRO` | **ID команды:** `krl.launchVirtualController` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Безопасное тестирование программ KRL в изолированной виртуальной машине OfficePC / Virtual KRC прямо с компьютера разработчика.

## ⚙️ Принцип работы
Интегрируется с гипервизорами и локальными эмуляторами KRC, запускает среду виртуального робота и настраивает сетевые мосты.

## 📂 Демонстрационный стенд / Файл
- `Настроенный виртуальный контроллер`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Запуск виртуального контроллера'.
2. Виртуальная среда KSS инициализируется и готова к приему программ.
