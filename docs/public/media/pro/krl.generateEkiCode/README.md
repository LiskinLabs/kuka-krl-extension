# Генератор типобезопасного драйвера приёма/передачи Ethernet KRL (EKI)

> **Категория:** `PRO` | **ID команды:** `krl.generateEkiCode` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.generateEkiCode`

---

## 🎯 Инженерная задача и ценность
Автоматическое написание громоздкого кода сетевого драйвера связи с камерой или SCADA-системой без ручной рутины.

## ⚙️ Принцип работы
На основе структуры XML-файла EKI автоматически генерирует парные файлы `.src` и `.dat` с функциями инициализации сокета `EKI_Init`, открытия соединения `EKI_Open`, чтения элементов через `EKI_GetInt`/`EKI_GetReal` и закрытия канала с обработкой таймаутов.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/eki_demo.xml`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. В файле `demo-workspace/eki_demo.xml` вызовите команду `KRL: Сгенерировать KRL-код для Ethernet KRL (EKI Driver)`.
2. Через секунду открывается сгенерированный файл `EkiDriver.src` с готовыми безопасными процедурами приёма и передачи координат камеры.
3. Покажите наличие встроенной обработки ошибок связи и проверки сетевых флагов.
