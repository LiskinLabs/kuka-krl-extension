# Свернуть все FOLD-оболочки в документе

> **Категория:** `FREE` | **ID команды:** `krl.foldAll` | **Горячие клавиши:** `Ctrl+K Ctrl+0`

---

## 🎯 Инженерная задача и ценность
Приведение программы к аккуратному компактному виду, как на пульте SmartPAD, скрывая тысячи служебных строк параметров движения.

## ⚙️ Принцип работы
Анализирует блочную структуру документа и сворачивает все регионы от ;FOLD до ;ENDFOLD.

## 📂 Демонстрационный стенд / Файл
- `Любой файл .src с большим количеством точек`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте насыщенную программу KRL.
2. Нажмите 'Ctrl+K Ctrl+0' или вызовите 'KRL: Свернуть всё'.
3. Все технологические фолды сворачиваются, на экране остаются только чистые заголовки.
