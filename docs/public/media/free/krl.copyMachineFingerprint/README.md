# Скопировать Hardware ID (отпечаток ПК) в буфер обмена

> **Категория:** `FREE` | **ID команды:** `krl.copyMachineFingerprint` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Быстрое копирование аппаратного идентификатора в буфер для отправки в службу поддержки или на сайт.

## ⚙️ Принцип работы
Генерирует стабильный аппаратный отпечаток ПК и копирует строку в буфер обмена ОС.

## 📂 Демонстрационный стенд / Файл
- `Любой ПК`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Скопировать Hardware ID'.
2. Идентификатор скопирован в буфер обмена с подтверждающим уведомлением.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот уведомления с Hardware ID
- **Рекомендуемые целевые файлы в эту папку:**
  - `copy_hwid_screen.png`
