# Интерактивный граф коммитов и ветвлений версий робота (Git Graph)

> **Категория:** `PRO` | **ID команды:** `krl.viewGitGraph` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.viewGitGraph`

---

## 🎯 Инженерная задача и ценность
Наглядный контроль эволюции версий программ робота в цеху: кто, когда и зачем изменял файлы ячейки.

## ⚙️ Принцип работы
Рендерит визуальное дерево коммитов Git репозитория робототехнического проекта с возможностью сравнения ревизий в 1 клик, просмотра авторов, тегов релизов и фильтрации по веткам производственных линий.

## 📂 Демонстрационный стенд / Файл
- `Любой Git-репозиторий робота`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите `KRL: Показать граф Git-коммитов проекта`.
2. Открывается красивая визуализация графа коммитов с цветными линиями веток.
3. Кликните на коммит — внизу отображается список затронутых файлов `.src`/`.dat`.
4. Кликните правой кнопкой мыши по файлу -> `Сравнить с предыдущей версией`.
