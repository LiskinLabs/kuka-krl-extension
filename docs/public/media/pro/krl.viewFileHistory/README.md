# Полная хронология и построчная история изменений KRL-файла (File History)

> **Категория:** `PRO` | **ID команды:** `krl.viewFileHistory` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.viewFileHistory`

---

##  Инженерная задача и ценность
Быстрое расследование сбоев: выяснить, в какой именно день и смену была изменена конкретная траектория или логика блокировки.

##  Принцип работы
Сканирует журнал Git для активного файла, выводит таймлайн всех ревизий с комментариями и позволяет мгновенно открыть Side-by-Side сравнение с любой исторической версией.

##  Демонстрационный стенд / Файл
- `demo-workspace/cell.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/cell.src`.
2. Вызовите `KRL: Показать историю изменений активного файла`.
3. В боковой панели раскрывается список коммитов, в которых участвовал данный файл.
4. Выберите исторический коммит — открывается моментальный diff изменений.
