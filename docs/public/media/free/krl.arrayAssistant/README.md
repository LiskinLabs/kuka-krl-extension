# Мастер генерации многомерных массивов KRL (1D, 2D, 3D) с циклами обхода

> **Категория:** `FREE` | **ID команды:** `krl.arrayAssistant` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.arrayAssistant`

---

## 🎯 Инженерная задача и ценность
Быстрое создание правильных объявлений массивов в `.dat` и шаблонов обхода вложенными циклами в `.src`.

## ⚙️ Принцип работы
Генерирует объявление массива нужной размерности с инициализацией дефолтными значениями и создает парный код со вложенными циклами `FOR i=1 TO N ... ENDFOR`.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/subroutines_and_functions.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите `KRL: Мастер создания массивов KRL (Array Assistant)`.
2. Выберите тип: `FRAME`, размерность: `2D (Матрица 4x6)`.
3. Нажмите `Сгенерировать` — плагин вставляет объявление массива в `.dat` и цикл обхода в `.src`.
