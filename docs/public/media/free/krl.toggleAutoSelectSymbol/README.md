# Умное автовыделение символов (двойной клик/ПКМ по переменным и знакам $)

> **Категория:** `FREE` | **ID команды:** `krl.toggleAutoSelectSymbol` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.toggleAutoSelectSymbol`

---

## 🎯 Инженерная задача и ценность
Удобство редактирования: выделение системных переменных KRL вместе со знаком доллара (`$OUT[1]`, `$OV_PRO`) в 1 клик.

## ⚙️ Принцип работы
Перехватывает выделение слов в редакторе и расширяет границу выделения, включая префикс `$`, который стандартный VS Code обычно считает отдельным знаком пунктуации.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/cell.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Дважды кликните по слову `$FLAG[12]` — оно выделяется целиком вместе со знаком `$` и скобками.
2. Покажите переключение режима через команду `KRL: Переключить умное автовыделение символов`.
