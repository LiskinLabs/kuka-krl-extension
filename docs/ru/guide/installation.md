# Установка и настройка KUKA KRL Professional

Руководство по быстрой установке, настройке и офлайн-активации расширения.

---

## 1. Установка из VS Code Marketplace
1. Откройте VS Code.
2. Перейдите во вкладку расширений (`Ctrl + Shift + X`).
3. Введите в поиске `KUKA KRL Professional` (Liskin Labs).
4. Нажмите **Install**.

---

## 2. Установка из VSIX-файла (Автономная установка / Offline)
1. Скачайте актуальный дистрибутив `kuka-krl-extension-1.9.8.vsix` из официального репозитория.
2. В VS Code откройте панель Extensions (`Ctrl + Shift + X`), нажмите меню с тремя точками `...` в правом верхнем углу панели.
3. Выберите пункт **Install from VSIX...** и укажите загруженный файл `.vsix`.
4. Перезагрузка редактора не требуется — расширение инициализируется мгновенно.

---

## 3. Выбор темы оформления KUKA
1. Нажмите сочетание клавиш `Ctrl + K`, затем `Ctrl + T`.
2. Выберите одну из 6 специализированных инженерных тем:
   * **Industrial Dark** (контрастная тема для заводских цехов)
   * **WorkVisual Dark** (цветовая палитра KUKA WorkVisual)
   * **WorkVisual Light** (светлый режим WorkVisual)
   * **Midnight OLED** (глубокий чёрный цвет для энергосбережения)
   * **Blueprint** (инженерная схема)
   * **Industrial Light** (классическая светлая тема)

---

## 4. Онлайн-активация Pro-лицензии
1. Откройте **KUKA Control Center**, кликнув по значку KUKA на панели Activity Bar слева или вызвав команду `KRL: Open Control Center` (`Ctrl + Shift + P`).
2. В блоке статуса лицензии нажмите кнопку **Ввести лицензионный ключ** (**Enter License Key**).
3. Вставьте приобретённый ключ и подтвердите ввод. Расширение свяжется со шлюзом лицензирования и активирует режим PRO.

---

## 5. Офлайн-активация в изолированных цеховых сетях (Air-Gap .lic)

Для режимных промышленных предприятий и закрытых OT-сетей без доступа к интернету предусмотрен детерминированный протокол асимметричного лицензирования по файлам `.lic` (криптография Ed25519):

### Шаг 1: Экспорт файла запроса Hardware ID (.lic)
1. На изолированном инженерном ноутбуке откройте **KUKA Control Center** -> вкладка **Настройки / Профиль** (`Settings & Account`).
2. В секции **Air-Gapped Offline Activation** нажмите кнопку **[Экспортировать запрос Hardware ID в файл (.lic)]** или вызовите команду `krl.exportHardwareIdFile` через палитру (`Ctrl + Shift + P`).
3. Сохраните сформированный файл `liskin-hardware-id.lic` на доверенный внешний накопитель (USB-flash).

### Шаг 2: Генерация лицензии на веб-портале
1. Подключите накопитель к ПК с выходом в интернет.
2. Перейдите на защищённый шлюз активации Liskin Labs:  
   👉 **[Портал офлайн-активации Air-Gap](https://kuka-krl-support-gateway.redminotpro5.workers.dev/airgap)**
3. Перетащите ваш файл `liskin-hardware-id.lic` в область загрузки или выберите его вручную — идентификатор оборудования заполнится автоматически.
4. Введите ваш лицензионный ключ (License Key) и нажмите **Сгенерировать офлайн-лицензию**.
5. Скачайте подписанный криптографический файл `liskin-krl-license.lic` на накопитель.

### Шаг 3: Импорт лицензии в VS Code
1. Вернитесь к изолированному ноутбуку в цеху.
2. В окне KUKA Control Center нажмите кнопку **[Загрузить файл офлайн-лицензии (.lic)]** или выполните команду `krl.importOfflineLicenseFile`.
3. Выберите файл `liskin-krl-license.lic`.
4. Расширение моментально валидирует асимметричную подпись Ed25519 без сетевых запросов и включит пожизненный или годовой режим **PRO** с сохранением полного доступа ко всем 50+ модулям.

| **Department / Integrator** | $999 / год | До 20 ПК | До 20 рабочих станций, неограниченные проекты интеграции, выделенная линия поддержки |

### Преимущества Pro Lifetime ($699) vs Enterprise Site ($4,999/год)
- **Pro Lifetime ($699 разово)** — бессрочная персональная лицензия на **1 рабочую станцию** без регулярных платежей, с пожизненными обновлениями и поддержкой выпуска автономных Air-Gapped файлов `.lic` для работы в закрытых сетях завода.
- **Enterprise Site ($4,999/год)** — комплексная заводская лицензия на **до 100 рабочих станций** для производственных предприятий и интеграторов: централизованный KUKA Fleet Backup Hub, кастомные правила линтинга под стандарты автоконцернов и выделенный инженерный SLA.
