# Сверка зон блокировок (длина в мм) и тех-точек с бэкапом

> **Категория:** `PRO` | **ID команды:** `krl.semanticInterlockDiff` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Защита от столкновений роботов в общих зонах: автоматическая сверка пространственных длин участков блокировок (FB PSPS) с эталонным бэкапом.

## ⚙️ Принцип работы
Вычисляет 3D длину траектории между точками входа и выхода из зоны блокировки в миллиметрах и сравнивает с эталонной версией. Сигнализирует о смещении технологических позиций.

## 📂 Демонстрационный стенд / Файл
- `Два бэкапа робота с зоной блокировки`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Запустите 'KRL: Сверка зон блокировок с эталоном'.
2. Выберите сравниваемый бэкап.
3. Отчет показывает точное отклонение траектории внутри защищенной зоны в миллиметрах.
