# Инструменты сплайнов (Modern Splines KSS 8.6+ / 8.7 & iiQKA)

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.insertSplineBlock` | **Обернуть в сплайн-блок (SPLINE Block)** | *Wrap in Modern SPLINE Block* |
| `krl.convertLegacyToSpline` | **Конвертировать в сплайны (KSS 8.6+ / 8.7)** | *Convert Legacy Motions to Modern Splines (KSS 8.6+ / 8.7)* |
| `krl.convertToIiqkaFold` | **Конвертировать в iiQKA Motion Fold** | *Convert Selection to iiQKA Motion Fold* |

## 🎯 Цель демонстрации и визуальный фокус
Превращение архаичного кода KUKA KSS 8.2/8.3 в современный сплайновый стандарт KSS 8.7 и iiQKA.

## 📂 Демонстрационный файл / Окружение
- `demo-workspace/motion_and_splines.src`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть `demo-workspace/motion_and_splines.src`.
2. Найти блок устаревших движений (PTP/LIN с $APO).
3. Выделить движения -> `Ctrl+Shift+P` -> `KRL: Конвертировать в сплайны (KSS 8.6+ / 8.7)` -> показать как PTP/LIN превращаются в SPL/SLIN с современными параметрами.
4. Выделить блок сплайн-движений -> `Ctrl+Shift+P` -> `KRL: Обернуть в сплайн-блок (SPLINE Block)` -> появляется конструкция `SPLINE ... ENDSPLINE` с оптимизированным профилем скорости.
5. Для платформы нового поколения iiQKA: выделить движения -> `KRL: Конвертировать в iiQKA Motion Fold` -> обертка в стандартизированные фолды iiQKA.
