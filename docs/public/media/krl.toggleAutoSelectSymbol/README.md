# Умное автовыделение символов (Smart Symbol Selection)

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.toggleAutoSelectSymbol` | **Переключить умное автовыделение символов (клик/ПКМ)** | *Toggle Smart Symbol Auto-Selection (Click/Right-Click)* |

## 🎯 Цель демонстрации и визуальный фокус
Удобство навигации: не нужно вручную протягивать курсор мыши через скобки и спецсимволы.

## 📂 Демонстрационный файл / Окружение
- `demo-workspace/logic_and_control_flow.src`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть любой файл с сложными именами переменных (например, `$OUT[12]`, `ST_PALLET_DATA[1].nBoxCount`).
2. Включить режим через `Ctrl+Shift+P` -> `KRL: Переключить умное автовыделение символов (клик/ПКМ)`.
3. Кликнуть левой или правой кнопкой мыши внутри имени переменной или системного массива.
4. Показать, что выделяется не отдельное слово, а весь промышленный идентификатор целиком вместе с индексами и точками структур.
