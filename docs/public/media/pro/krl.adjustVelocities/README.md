# Пакетное масштабирование и ограничение скоростей ($VEL.CP, $VEL_AXIS)

> **Категория:** `FREE` | **ID команды:** `krl.adjustVelocities` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.adjustVelocities`

---

##  Инженерная задача и ценность
Быстрое пропорциональное замедление программы на этапе первоначальной отладки или ускорение для оптимизации такта.

##  Принцип работы
Находит все операторы назначения линейных (`$VEL.CP = ...`) и осевых скоростей (`$VEL_AXIS[...] = ...`) и умножает их значения на коэффициент (например, 0.5 для замедления на 50%).

##  Демонстрационный стенд / Файл
- `demo-workspace/welding_process.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте файл программы.
2. Вызовите `KRL: Пакетное масштабирование скоростей программы`.
3. Введите масштабный коэффициент: `0.7` (70% от исходной скорости).
4. Все параметры скоростей в `.src` и `.dat` синхронно пересчитываются.
