# Отключить связь с контроллером KRC

> **Категория:** `PRO` | **ID команды:** `krl.live.disconnect` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Безопасный разрыв сетевой сессии телеметрии с контроллером робота.

## ⚙️ Принцип работы
Корректно закрывает TCP/IP сокеты и освобождает сетевые дескрипторы на контроллере.

## 📂 Демонстрационный стенд / Файл
- `Активное подключение`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'KRL: Отключить связь с контроллером'.
2. Соединение мгновенно закрывается, ресурсы освобождаются.
