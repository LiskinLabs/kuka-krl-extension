# Базовая проверка синтаксиса и целостности файлов проекта (Check All Files)

> **Категория:** `FREE` | **ID команды:** `krl.validateWorkspace` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.validateWorkspace`

---

## 🎯 Инженерная задача и ценность
Сканирование всех файлов проекта на базовые синтаксические ошибки KRL без необходимости открывать каждый файл по отдельности.

## ⚙️ Принцип работы
Проходит по всем файлам с расширениями `.src`, `.dat`, `.sub`, парсит структуру DEF/END, FOLD/ENDFOLD, проверяет баланс скобок и регистрирует найденные проблемы в стандартной панели VS Code Problems.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/diagnostics_demo.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте папку `demo-workspace`.
2. Вызовите `KRL: Проверить все файлы проекта (Validate Workspace)`.
3. В нижней панели `Problems` появляется список обнаруженных синтаксических предупреждений с указанием строк и файлов.
4. Кликните на ошибку — редактор мгновенно открывает проблемный файл и фокусирует курсор.
