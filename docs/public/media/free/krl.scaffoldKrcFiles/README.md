# Инициализация эталонных системных файлов контроллера ($config.dat, SPS.SUB)

> **Категория:** `FREE` | **ID команды:** `krl.scaffoldKrcFiles` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.scaffoldKrcFiles`

---

##  Инженерная задача и ценность
Быстрое развертывание нового робототехнического проекта с нуля с правильной структурой заводских файлов.

##  Принцип работы
Создает эталонную иерархию папок `KRC/R1/System` и `KRC/R1/Program`, генерирует валидные файлы `$config.dat`, `$machine.dat`, `$robcor.dat`, фоновую задачу `SPS.SUB` и главный диспетчер `Cell.src`.

##  Демонстрационный стенд / Файл
- `Пустая рабочая папка проекта`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. В пустой папке вызовите `KRL: Инициализировать стандартные системные файлы KSS 8.7`.
2. В проводнике мгновенно разворачивается полноценный скелет заводского проекта робота KUKA со всеми стандартными файлами.

##  Рекомендуемый визуальный формат
- **Формат:** Анимированный GIF (8 сек) + Скриншот структуры (PNG)
- **Рекомендуемые целевые файлы в эту папку:**
  - `scaffold_krc_demo.gif`
  - `scaffold_krc_screen.png`
