# Умное дублирование фолда движения (Создание точки в .DAT)

> **Категория:** `PRO` | **ID команды:** `krl.smartDuplicateMotionFold` | **Горячие клавиши:** `Ctrl+Shift+D`

---

## 🎯 Инженерная задача и ценность
Создание новой промежуточной точки траектории нажатием одной клавиши: автоматическое создание фолда в .src и уникальной структуры DECL в .dat.

## ⚙️ Принцип работы
Определяет активный фолд движения (PTP, LIN), генерирует следующее свободное имя (например, P2 -> P3), копирует текущие координаты в companion .dat файл и вставляет синхронизированный Inline Form в .src.

## 📂 Демонстрационный стенд / Файл
- `Любая траектория .src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Установите курсор на строку движения LIN или PTP.
2. Нажмите 'Ctrl+Shift+D'.
3. Новая точка создана в обеих программах (.src и .dat) без необходимости ручного редактирования.
