# Интерактивная блок-схема и граф переходов (Control Flow Graph)

> **Категория:** `PRO` | **ID команды:** `krl.showFlowchart` | **Горячие клавиши:** `Ctrl+Alt+F`

---

## 🎯 Инженерная задача и ценность
Визуализация логики алгоритма KRL: разбор ветвлений IF/THEN/ELSE, циклов LOOP/FOR/WHILE, переходов GOTO и вызовов подпрограмм в виде масштабируемой интерактивной диаграммы.

## ⚙️ Принцип работы
Парсит активный .src файл в AST-дерево, строит ориентированный граф потока управления (CFG) через Mermaid/SVG, подсвечивает опасные ветки и бесконечные циклы без EXIT. При клике на узел диаграммы переносит курсор на соответствующую строку в коде.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/flowchart_demo.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте файл `demo-workspace/flowchart_demo.src` в редакторе.
2. Нажмите комбинацию клавиш `Ctrl+Alt+F` или выполните команду `KRL: Показать блок-схему (Control Flow Graph)`.
3. Справа откроется Webview-панель с интерактивной блок-схемой.
4. Покажите масштабирование колесиком мыши (Zoom) и перетаскивание графа (Pan).
5. Кликните на узел `CHECK_SAFETY_OK` — в левом редакторе строка автоматически подсветится.
6. Нажмите кнопку смены темы (Light/Dark) и кнопку экспорта SVG/PNG.
