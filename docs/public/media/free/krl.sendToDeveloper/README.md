# Отправить разработчику диагностический пакет

> **Категория:** `FREE` | **ID команды:** `krl.sendToDeveloper` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Быстрая отправка логов ошибок или баг-репорта напрямую инженеру для оперативного выпуска патча.

## ⚙️ Принцип работы
Собирает анонимизированные логи расширения и формирует удобное сообщение разработчику.

## 📂 Демонстрационный стенд / Файл
- `Окно ввода описания проблемы`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'KRL: Отправить разработчику…'.
2. Кратко опишите проблему.
3. Диагностика отправлена разработчику.

- **Формат:** Скриншот диалога отправки
