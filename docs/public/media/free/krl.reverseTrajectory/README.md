# Реверс траектории движения манипулятора (Path Inversion)

> **Категория:** `FREE` | **ID команды:** `krl.reverseTrajectory` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.reverseTrajectory`

---

## 🎯 Инженерная задача и ценность
Автоматическое создание траектории безопасного отхода робота назад по тем же точкам, по которым он заходил в рабочую зону.

## ⚙️ Принцип работы
Инвертирует последовательность точек движения в выделенном блоке, меняя порядок P1 -> P2 -> P3 на P3 -> P2 -> P1 с сохранением типов движения и скоростей.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/motion_and_splines.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Выделите траекторию захода робота внутрь станка.
2. Вызовите `KRL: Реверс траектории движения (Path Inversion)`.
3. Код автоматически переворачивается в обратную сторону для безопасного вывода манипулятора.
