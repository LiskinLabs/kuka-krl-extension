# Скопировать сообщение коммита для текущей строки

> **Категория:** `FREE` | **ID команды:** `krl.copyCommitMessage` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Быстрое получение комментария коммита (номер задачи, описание изменений) для отчета.

## ⚙️ Принцип работы
Считывает сообщение коммита Git blame для текущей строки и копирует в буфер обмена.

## 📂 Демонстрационный стенд / Файл
- `Файл под версионным контролем`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Скопировать сообщение коммита'.
2. Комментарий коммита скопирован в буфер.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот уведомления
- **Рекомендуемые целевые файлы в эту папку:**
  - `copy_commit_msg_screen.png`
