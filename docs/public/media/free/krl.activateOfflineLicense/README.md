# Активация Air-Gapped офлайн-лицензии по ключу

> **Категория:** `FREE` | **ID команды:** `krl.activateOfflineLicense` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Активация Pro-функций на изолированных промышленных ноутбуках на режимных заводах без доступа к интернету.

## ⚙️ Принцип работы
Принимает криптографический лицензионный ключ с цифровой подписью Ed25519, привязанный к аппаратному отпечатку ПК (Hardware ID).

## 📂 Демонстрационный стенд / Файл
- `Окно ввода лицензионного ключа`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Активировать Air-Gapped офлайн-лицензию'.
2. Вставьте криптографический ключ, полученный на сайте.
3. Лицензия мгновенно активирована с пожизненным сроком действия.
