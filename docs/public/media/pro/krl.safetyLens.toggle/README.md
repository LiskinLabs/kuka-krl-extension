# Safety Lens: подсветка опасных инструкций, отсутствия BRAKE и бросков скоростей

> **Категория:** `PRO` | **ID команды:** `krl.safetyLens.toggle` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.safetyLens.toggle`

---

##  Инженерная задача и ценность
Визуальное выделение опасных участков кода прямо в редакторе периферийным зрением инженера.

##  Принцип работы
Анализирует текст на лету. Подсвечивает яркими предупреждающими иконками и фоновыми градиентами потенциально опасные конструкции: команду `RESUME` без `BRAKE` в подпрограммах прерываний (вызывает ошибку KSS 1422), неконтролируемые присваивания `$OV_PRO = 100` и опасные модификаторы движения.

##  Демонстрационный стенд / Файл
- `demo-workspace/diagnostics_demo.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/diagnostics_demo.src`.
2. Вызовите `KRL: Включить/выключить подсветку рисков безопасности (Safety Lens)`.
3. В коде появляются контрастные индустриальные плашки опасности: `[WARN] HAZARD: Missing BRAKE before RESUME` и `[WARN] High Velocity Jump`.
4. Покажите исчезновение плашки сразу после исправления кода.
