# Управление FOLD-регионами (Сворачивание / Разворачивание / Обертка)

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.foldAll` | **Свернуть всё** | *Fold All* |
| `krl.unfoldAll` | **Развернуть всё** | *Unfold All* |
| `krl.insertFold` | **Вставить FOLD-регион** | *Insert FOLD Region* |
| `krl.unwrapFold` | **Развернуть / Очистить FOLD-оболочки** | *Unwrap / Strip FOLD Envelopes* |

## 🎯 Цель демонстрации и визуальный фокус
Показать плавность сворачивания кода, фирменные иконки в тулбаре редактора и чистоту удаления FOLD-комментариев.

## 📂 Демонстрационный файл / Окружение
- `demo-workspace/logic_and_control_flow.src`
- `demo-workspace/pick_and_place.src`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть `demo-workspace/logic_and_control_flow.src` в редакторе.
2. Обратить внимание на тулбар в верхнем правом углу редактора: иконки сворачивания и разворачивания.
3. Нажать иконку `Свернуть всё` (krl.foldAll) -> весь файл компактно сворачивается по границам FOLD и DEF.
4. Нажать иконку `Развернуть всё` (krl.unfoldAll) -> код мгновенно раскрывается.
5. Выделить 5-10 строк кода движения или логики -> Нажать `Ctrl+Shift+P` -> Выбрать `KRL: Вставить FOLD-регион` (krl.insertFold) -> Ввести имя фолда (например, USER_MOTION) -> код оборачивается в `;FOLD USER_MOTION ... ;ENDFOLD`.
6. Поставить курсор внутри фолда -> `Ctrl+Shift+P` -> `KRL: Развернуть / Очистить FOLD-оболочки` (krl.unwrapFold) -> фолд аккуратно удаляется, оставляя только чистый код.
