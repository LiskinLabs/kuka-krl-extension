# Инспектор топологии шин и KOP опций WorkVisual (.wvs / .wvps)

> **Категория:** `PRO` | **ID команды:** `krl.inspectWvsTopology` | **Горячие клавиши:** `Ctrl+Shift+W`

---

## 🎯 Инженерная задача и ценность
Анализ аппаратного состава робота, установленных технологических пакетов KOP (EthernetKRL, SafeOperation, GripperSpotTech) и шинной топологии EtherCAT/Profinet без необходимости запуска громоздкого WorkVisual.

## ⚙️ Принцип работы
Выполняет прямое чтение двоичного архива WorkVisual (.wvs/.wvps), декодирует hex-экранированные XML структуры (_x003C_), извлекает паспорта осей SafeMaDaBusTopology, перечень подчиненных устройств EtherCAT (EcatDiag) и формирует интерактивный отчет сопоставления $IN/$OUT сигналов.

## 📂 Демонстрационный стенд / Файл
- `WorkVisual бэкап или демо .wvs архив`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите правой кнопкой на файл проекта .wvs или вызовите команду 'KRL: Инспектор топологии шин WorkVisual'.
2. Расширение за 0.3 секунды сканирует структуру проекта без извлечения на диск.
3. В открывшейся панели отображается дерево шины EtherCAT/Profinet, версии установленных пакетов KOP и полная карта аппаратных адресов сигналов.
