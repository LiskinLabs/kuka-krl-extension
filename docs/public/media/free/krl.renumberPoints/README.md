# Автоматическая перенумерация точек P1..Pn с синхронизацией .dat

> **Категория:** `FREE` | **ID команды:** `krl.renumberPoints` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.renumberPoints`

---

## 🎯 Инженерная задача и ценность
Наведение порядка после многократного добавления и удаления точек, когда номера идут вперемешку (P1, P15, P3, P22).

## ⚙️ Принцип работы
Последовательно переименовывает все точки по ходу движения в `P1`, `P2`, `P3`... и автоматически обновляет их имена и структуры координат в парном `.dat` файле.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/motion_and_splines.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте программу с хаотичными номерами точек.
2. Вызовите `KRL: Перенумеровать точки траектории и синхронизировать .dat`.
3. Все имена точек становятся строго последовательными P1..Pn, и парный `.dat` синхронизируется.
