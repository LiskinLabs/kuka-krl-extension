# Скаффолдинг проектов KSS 8.7 и полная проверка воркспейса

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.scaffoldKrcFiles` | **Инициализировать системные файлы KSS 8.7** | *Initialize Standard KSS 8.7 System Files* |
| `krl.validateWorkspace` | **Проверить все файлы** | *Check All Files* |

## 🎯 Цель демонстрации и визуальный фокус
Старт нового проекта за 2 секунды без поиска старых шаблонов на флешках.

## 📂 Демонстрационный файл / Окружение
- `Чистая папка проекта / Рабочее пространство`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. В пустой папке нажать `Ctrl+Shift+P` -> `KRL: Инициализировать системные файлы KSS 8.7`.
2. Мгновенно генерируются эталонные файлы: `$config.dat`, `$machine.dat`, `cell.src`, `am.ini` с корректными заголовками WorkVisual.
3. Вызвать `KRL: Проверить все файлы` (krl.validateWorkspace) -> расширение пакетно сканирует файлы и выводит сводный статус в статус-бар.
