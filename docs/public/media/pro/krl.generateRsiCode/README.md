# Генератор 4 мс KRL-драйвера и XML для KUKA.RSI

> **Категория:** `PRO` | **ID команды:** `krl.generateRsiCode` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Генерация надежного программного цикла коррекции в реальном времени с поддержкой высокоскоростного такта #IPO_FAST (4 мс) и стандартного #IPO (12 мс).

## ⚙️ Принцип работы
Формирует детерминированный KRL-код вызовов RSI_CREATE, RSI_ON, RSI_MOVECORR, RSI_OFF, RSI_DELETE с обработкой кодов возврата (RSIOK, RSITIMEOUT) и парный XML-дескриптор связи.

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Сгенерировать драйвер реального времени RSI'.
2. Выберите тип управления: Декартов (Cartesian RKorr) или Поосевой (ROS 2 Axis).
3. В редакторе создается готовый драйвер с безопасной обработкой аварийных остановов.
