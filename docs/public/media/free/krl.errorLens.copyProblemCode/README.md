# Error Lens: Скопировать числовой код ошибки (KSS)

> **Категория:** `FREE` | **ID команды:** `krl.errorLens.copyProblemCode` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Копирование точного кода ошибки (например, KSS01442) для быстрого поиска в справочной документации KUKA.

## ⚙️ Принцип работы
Извлекает код ошибки из диагностического объекта и копирует в буфер обмена.

## 📂 Демонстрационный стенд / Файл
- `Строка с ошибкой KSS`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'Error Lens: Скопировать код ошибки'.
2. Код ошибки KSS скопирован в буфер.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот копирования кода
