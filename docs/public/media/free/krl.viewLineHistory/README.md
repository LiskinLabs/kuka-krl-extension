# История изменений выделенных строк (git log -L)

> **Категория:** `FREE` | **ID команды:** `krl.viewLineHistory` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Отслеживание полной эволюции конкретной траектории или критического участка логики за все годы.

## ⚙️ Принцип работы
Запускает анализ git log -L для выбранного диапазона строк и строит хронологический список правок.

## 📂 Демонстрационный стенд / Файл
- `Критический участок кода`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Выделите строки движения и вызовите команду.
2. Открывается панель с полной историей изменения этих конкретных строк.

- **Формат:** GIF (8 сек) просмотра истории строк
