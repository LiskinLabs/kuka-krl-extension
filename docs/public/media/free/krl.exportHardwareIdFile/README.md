# Экспортировать запрос Hardware ID в файл (.lic)

> **Категория:** `FREE` | **ID команды:** `krl.exportHardwareIdFile` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Мгновенное формирование файла запроса лицензии для передачи на сайт генератора офлайн-ключей.

## ⚙️ Принцип работы
Вычисляет композитный аппаратный хэш машины (CPU, материнская плата, UUID диска) и сохраняет его в файл Hardware_ID_Request.lic на рабочий стол.

## 📂 Демонстрационный стенд / Файл
- `Любой ПК`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'KRL: Экспортировать запрос Hardware ID в файл (.lic)'.
2. Файл автоматически сохранен.
3. Загрузите этот файл на сайт генератора для мгновенного получения активирующей лицензии.
