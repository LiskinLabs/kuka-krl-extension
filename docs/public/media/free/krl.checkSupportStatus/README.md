# Проверить статус шлюза технической поддержки

> **Категория:** `FREE` | **ID команды:** `krl.checkSupportStatus` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Контроль доступности облачных сервисов Liskin Labs (лицензирование, чат поддержки, синхронизация).

## ⚙️ Принцип работы
Выполняет HTTPS health-check шлюза Cloudflare Workers и сообщает пинг и статус соединения.

## 📂 Демонстрационный стенд / Файл
- `Строка состояния`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Проверить статус шлюза поддержки'.
2. Получите подтверждение: 'Сервер поддержки онлайн (200 OK, 38ms)'.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот уведомления о статусе
