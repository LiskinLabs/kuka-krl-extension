# Навигация F12: мгновенный переход к определению подпрограмм и данных

> **Категория:** `FREE` | **ID команды:** `krl.gotoDefinition` | **Горячие клавиши:** `F12 / Ctrl+Click`

---

## 🎯 Инженерная задача и ценность
Мгновенная навигация между `.src` и `.dat` файлами и внешними подпрограммами в масштабных проектах из сотен модулей.

## ⚙️ Принцип работы
Использует встроенный индексатор символов LSP. При нажатии F12 мгновенно переносит фокус в место объявления переменной, структуры, константы или точки в `.dat` файле.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/main.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. В `demo-workspace/main.src` наведите курсор на вызов подпрограммы `WeldCycle()`.
2. Нажмите клавишу `F12` (или `Ctrl+Click`).
3. Редактор мгновенно открывает файл `welding_process.src` точно на строке `DEF WeldCycle()`.
4. Нажмите `F12` на переменной `XP_WELD_START` — фокус переходит в парный файл `welding_process.dat`.
