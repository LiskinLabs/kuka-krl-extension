# Очистка кода, сортировка деклараций и удаление мусора WorkVisual

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.sortDeclarations` | **Сортировать объявления** | *Sort Declarations* |
| `krl.cleanupUnusedVariables` | **Удалить неиспользуемые переменные** | *Clean Up Unused Variables* |
| `krl.cleanGitMetadata` | **Очистка Git-метаданных WorkVisual** | *Clean WorkVisual Git Metadata* |

## 🎯 Цель демонстрации и визуальный фокус
Эффект «До / После» — мгновенное приведение неопрятного цехового кода к чистому инженерному стандарту.

## 📂 Демонстрационный файл / Окружение
- `demo-workspace/formatting_demo.src`
- `demo-workspace/git_clean_demo.src`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть `demo-workspace/formatting_demo.src` (в начале файла переменные объявлены вразброс: INT, REAL, BOOL, GLOBAL).
2. Вызвать команду `KRL: Сортировать объявления` -> переменные аккуратно группируются по типам и алфавиту в заголовке функции.
3. Запустить `KRL: Удалить неиспользуемые переменные` -> линтер находит объявленные, но не вызываемые в теле переменные и безопасно удаляет их строки.
4. Открыть `demo-workspace/git_clean_demo.src` с метаданными WorkVisual (`&ACCESS`, `&REL`, `&PARAM`) -> вызвать `KRL: Очистка Git-метаданных WorkVisual` -> служебные теги удаляются, файл готов для чистого Git коммита.
