# Проверка XML-конфигурации KUKA.RobotSensorInterface (RSI)

> **Категория:** `PRO` | **ID команды:** `krl.validateRsiXml` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Предотвращение сбоев высокоскоростной шины коррекции траекторий KUKA.RSI (4 мс) из-за синтаксических ошибок и пропусков параметров в XML-схемах.

## ⚙️ Принцип работы
Проверяет валидность тегов `<CONFIG>`, `<IP_NUMBER>`, `<PORT>`, порядок элементов `<INDX>`, непрерывность входных/выходных потоков для Cartesian (RKorr) и Axis (AK).

## 📂 Демонстрационный стенд / Файл
- `SensorInterface/RsiConfig.xml`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте файл конфигурации RSI XML.
2. Вызовите 'KRL: Проверить XML-конфигурацию RSI'.
3. Получите отчет валидации с подсветкой нарушений диапазона портов и непрерывности индексов.
