# Запросить официальный B2B счет / Angebot (PDF & EU VAT 0%)

> **Категория:** `FREE` | **ID команды:** `krl.requestCorporateInvoice` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Оформление коммерческого предложения и счета для юридических лиц с нулевым НДС для компаний ЕС и безналичным расчетом.

## ⚙️ Принцип работы
Открывает интерактивный мастер ввода реквизитов компании (название, VAT ID, адрес, email бухгалтерии) и отправляет запрос на генерацию официального счета.

## 📂 Демонстрационный стенд / Файл
- `Мастер B2B счетов`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Запросить официальный B2B счет'.
2. Введите название компании и VAT ID.
3. Официальный Angebot PDF сгенерирован и отправлен на email.
