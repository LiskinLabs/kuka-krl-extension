# Error Lens: Включить/выключить подсветку ошибок в строках

> **Категория:** `FREE` | **ID команды:** `krl.errorLens.toggle` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Отображение диагностических сообщений и ошибок компилятора прямо в строках кода без необходимости открывать панель Проблемы.

## ⚙️ Принцип работы
Интегрирует декораторы ошибок и предупреждений с цветовой дифференциацией в активном редакторе.

## 📂 Демонстрационный стенд / Файл
- `Файл с синтаксической ошибкой`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Включите Error Lens.
2. Ошибки подсвечиваются ярким текстом в конце проблемных строк кода.
