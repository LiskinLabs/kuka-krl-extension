# Деплой активной программы в виртуальный контроллер [PRO]

> **Категория:** `PRO` | **ID команды:** `krl.deployToVirtualController` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Мгновенная загрузка отредактированного кода KRL в виртуальный робот для проверки синтаксиса и прогона траекторий.

## ⚙️ Принцип работы
Синхронизирует активные файлы .src/.dat с сетевой рабочей папкой виртуального контроллера без необходимости ручного копирования.

## 📂 Демонстрационный стенд / Файл
- `Активная программа .src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте программу и нажмите 'KRL: Деплой в виртуальный контроллер'.
2. Файл отправлен и мгновенно доступен в интерпретаторе виртуального робота.
