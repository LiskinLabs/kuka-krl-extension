# Аудит и авторемонт симуляции KUKA.Sim VCMX (VCMX001-VCMX004)

> **Категория:** `PRO` | **ID команды:** `krl.validateVcmxSimulation` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Выявление и автоматическое исправление 4 критических дефектов логики симуляции, приводящих к зависанию робота в KUKA.Sim и Visual Components.

## ⚙️ Принцип работы
Детектирует импульсные сигналы без подтверждения (VCMX001), таймауты WaitSignal (VCMX002), утечки памяти в очередях изделий TransportOut (VCMX003) и висячие ссылки на сигналы (VCMX004) с созданием версионных бэкапов .bk1.

## 📂 Демонстрационный стенд / Файл
- `Файл проекта KUKA.Sim с дефектами сигналов`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Запустите 'KRL: Аудит симуляции KUKA.Sim VCMX'.
2. Ознакомьтесь с найденными потенциальными дедлоками сигналов.
3. Нажмите 'Исправить дефекты' — архив безопасно пропатчивается с сохранением резервной копии.
