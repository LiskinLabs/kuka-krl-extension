# Таблица точек KRL и 6D FK/IK редактор (Пересчет Tool/Base)

> **Категория:** `PRO` | **ID команды:** `krl.openPointTableEditor` | **Горячие клавиши:** `Ctrl+Alt+P`

---

## 🎯 Инженерная задача и ценность
Пакетное редактирование координат массива точек, пересчет в разные системы координат Tool/Base и решение прямой/обратной задачи кинематики прямо в редакторе.

## ⚙️ Принцип работы
Парсит переменные E6POS, POS, E6AXIS в интерактивную таблицу. Позволяет одним кликом сменить базовую систему координат с пересчетом декартовых координат фланца через кинематический решатель Liskin Labs Solver.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/points_demo.dat`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите 'Ctrl+Alt+P' в файле .dat с точками.
2. Открывается табличный редактор точек со столбцами X, Y, Z, A, B, C, S, T.
3. Выберите 'Пересчитать из Base 1 в Base 5' — координаты мгновенно пересчитываются с сохранением исходного положения в пространстве ячейки.
