# Переименовать сигнал с авто-рефакторингом по проекту

> **Категория:** `FREE` | **ID команды:** `krl.renameSignal` | **Горячие клавиши:** `F2 (на сигнале)`

---

## 🎯 Инженерная задача и ценность
Безопасное переименование имени сигнала сразу во всех подпрограммах проекта без риска пропустить вызов.

## ⚙️ Принцип работы
Находит объявление SIGNAL и все вхождения использования в .src/.dat/.sub файлах и выполняет согласованный рефакторинг.

## 📂 Демонстрационный стенд / Файл
- `KRC/R1/System/$config.dat`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Поставьте курсор на имя сигнала и нажмите F2.
2. Введите новое имя.
3. Сигнал переименован во всех 100+ файлах проекта.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** GIF (8 сек) рефакторинга имени сигнала
- **Рекомендуемые целевые файлы в эту папку:**
  - `rename_signal_demo.gif`
  - `rename_signal_screen.png`
