# Трехсторонняя синхронизация целостности точек (Fold <-> .DAT)

> **Категория:** `PRO` | **ID команды:** `krl.resolveDataIntegrity3Way` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Устранение рассинхронизации данных движения: проверка согласованности заголовка FOLD, внутренних инструкций BAS/FDAT и фактических объявлений в .DAT файле.

## ⚙️ Принцип работы
Проводит перекрестную 3-стороннюю валидацию. При обнаружении расхождений (например, в заголовке FDAT_ACT=FP1, а в теле BAS(#FRAMES, 2)) предлагает пакетное приведение к единому источнику правды.

## 📂 Демонстрационный стенд / Файл
- `Архив бэкапа с рассогласованными фолдами`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: 3-сторонняя синхронизация целостности точек'.
2. Расширение находит скрытые расхождения параметров движения.
3. Нажмите 'Синхронизировать всё' — все расхождения устраняются в один клик.
