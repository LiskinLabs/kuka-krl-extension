# Вставка точки на траектории на расстоянии (мм / %, SLERP)

> **Категория:** `PRO` | **ID команды:** `krl.insertPointOnPath` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Врезка технологической точки (включение горелки, дозатора клея, сброс скорости) строго на линии существующей траектории без искажения пространственного пути.

## ⚙️ Принцип работы
Выполняет 3D линейную интерполяцию для LIN и сферическую кватернионную интерполяцию (SLERP) для ориентаций A, B, C дуг CIRC на заданном расстоянии в миллиметрах или процентах длины сегмента.

## 📂 Демонстрационный стенд / Файл
- `Траектория сварки или склейки .src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Выделите сегмент движения между двумя точками.
2. Вызовите 'KRL: Вставить точку на траектории'.
3. Задайте смещение (например, '250 мм от начала' или '50%').
4. Новая расчетная точка рассчитывается и встраивается в траекторию.
