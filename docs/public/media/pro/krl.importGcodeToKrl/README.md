# Импорт CAM CNC G-Code (.nc/.gcode) и контуров SVG (.svg) в KRL

> **Категория:** `PRO` | **ID команды:** `krl.importGcodeToKrl` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Превращение промышленного робота в обрабатывающий фрезерный ЧПУ-станок или контурный плоттер без покупки дорогостоящих сторонних CAM-постпроцессоров.

## ⚙️ Принцип работы
Транслирует кадры ISO G-Code (G0 -> PTP, G1 -> LIN, G2/G3 -> CIRC с автоматическим расчетом промежуточной 3D-точки XAUX, пересчетом подачи F в $VEL.CP) и векторные кривые SVG в KRL-траекторию с companion .dat.

## 📂 Демонстрационный стенд / Файл
- `Контур детали .nc или логотип .svg`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Импорт CAM G-Code / SVG в KRL'.
2. Выберите файл управляющей программы ЧПУ или векторный файл SVG.
3. Укажите целевую плоскость (XY, XZ), номера Tool/Base и скорость подачи.
4. Получите чистую траекторию KRL со сглаживанием C_DIS.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Анимированный GIF (12 сек) трансформации ЧПУ-кода в траекторию KRL
- **Рекомендуемые целевые файлы в эту папку:**
  - `gcode_import_demo.gif`
  - `gcode_import_screen.png`
