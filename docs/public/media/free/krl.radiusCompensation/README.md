# Эквидистантная 2D-коррекция траектории на радиус инструмента фрезы (G41/G42)

> **Категория:** `FREE` | **ID команды:** `krl.radiusCompensation` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.radiusCompensation`

---

## 🎯 Инженерная задача и ценность
Коррекция траектории фрезерования или плазменной резки при смене диаметра режущего инструмента без повторной генерации в CAM-системе.

## ⚙️ Принцип работы
Вычисляет нормали к каждому сегменту контура и смещает всю 2D-траекторию влево или вправо на заданную величину радиуса фрезы Delta R с автоматическим расчетом точек сопряжения.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/motion_and_splines.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Выделите контурные точки в файле.
2. Вызовите `KRL: Коррекция 2D-контура на радиус инструмента`.
3. Выберите сторону смещения (Слева / Справа) и введите радиус (например, `5.0 мм`).
4. Координаты точек пересчитываются со смещением по эквидистанте.
