# Error Lens: Включить/выключить текст ошибки в строке

> **Категория:** `FREE` | **ID команды:** `krl.errorLens.toggleInlineMessage` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Возможность оставить только цветную подсветку строки без длинного поясняющего текста, если экран компактный.

## ⚙️ Принцип работы
Переключает режим рендеринга текстового суффикса ошибок в активном редакторе.

## 📂 Демонстрационный стенд / Файл
- `Файл с синтаксической ошибкой`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'Error Lens: Включить/выключить текст в строке'.
2. Текст ошибки скрывается, остается только аккуратный значок и подсветка.
