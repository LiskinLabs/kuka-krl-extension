# Синхронизация и обратная упаковка изменений в ZIP-архив контроллера

> **Категория:** `PRO` | **ID команды:** `krl.syncAllToBackupZip` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.syncAllToBackupZip`

---

## 🎯 Инженерная задача и ценность
Сохранение внесенных правок прямо обратно в исходный ZIP-архив бэкапа для немедленной загрузки на робот через USB-флешку.

## ⚙️ Принцип работы
Отслеживает все измененные в VS Code файлы, пересобирает ZIP-архив с сохранением оригинальных контрольных сумм CRC32 и прав доступа, гарантируя совместимость со встроенным загрузчиком KUKA SmartHMI.

## 📂 Демонстрационный стенд / Файл
- `Смонтированный рабочий проект бэкапа`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Внесите изменение в смонтированный `.src` файл.
2. Нажмите `Ctrl+Shift+P` -> `KRL: Синхронизировать все изменения обратно в ZIP-архив бэкапа`.
3. В правом нижнем углу всплывает уведомление об успешной упаковке с хешем SHA-256 обновленного архива.
