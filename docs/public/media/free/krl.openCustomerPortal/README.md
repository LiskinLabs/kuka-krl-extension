# Личный кабинет и инвойсы (Dodo Payments)

> **Категория:** `FREE` | **ID команды:** `krl.openCustomerPortal` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Управление корпоративными счетами, смена платежных реквизитов и скачивание официальных инвойсов.

## ⚙️ Принцип работы
Генерирует одноразовую защищенную сессию биллинга и открывает личный кабинет Dodo Payments в браузере.

## 📂 Демонстрационный стенд / Файл
- `Браузер`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Личный кабинет и инвойсы'.
2. В браузере открывается защищенный портал биллинга с историей оплат и PDF инвойсами.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот личного кабинета
