## 🎯 Цель демонстрации и визуальный фокус
Мощнейшая математическая кинематика прямо в редакторе: избавляет от необходимости переобучать робота вручную.

## 📂 Демонстрационный файл / Окружение
- `demo-workspace/pick_and_place.src`
- `demo-workspace/pick_and_place.dat`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть `demo-workspace/pick_and_place.src`.
2. Вызвать `KRL: Зеркалирование траектории и координат (6D)` -> Выбрать плоскость зеркалирования (XZ или YZ) -> точки в файле и в `.dat` автоматически пересчитываются с инверсией координат и правильным статусом S/T.
3. Вызвать `KRL: Пакетное смещение точек (Tool/Base/Vector)` -> задать вектор смещения (например, Z +100 мм) -> все точки смещаются на 100 мм.
4. Вызвать `KRL: Реверс траектории движения` -> порядок обхода точек инвертируется (для возвратного движения манипулятора).
5. Вызвать `KRL: Перенумерация точек и синхронизация .dat` -> точки нумеруются по порядку `P1, P2, P3...` с синхронизацией структур в `.dat`.
6. Вызвать `KRL: Обзор координат Tool и Base` -> открывается сводная таблица калибровок инструментов и баз.
