# Error Lens: отображение ошибок диагностики прямо в строках редактора

> **Категория:** `FREE` | **ID команды:** `krl.errorLens` | **Горячие клавиши:** `Автоматически в редакторе`

---

##  Инженерная задача и ценность
Моментальное обнаружение синтаксических ошибок без необходимости постоянно смотреть вниз в панель вывода.

##  Принцип работы
Рендерит текст предупреждений и ошибок прямо в конце проблемной строки редактора ярким контрастным цветом, предоставляет быстрое действие для копирования кода ошибки или поиска решения в интернете.

##  Демонстрационный стенд / Файл
- `demo-workspace/diagnostics_demo.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/diagnostics_demo.src`.
2. На строке с ошибкой (например, пропущенный `THEN` в `IF`) прямо в коде выводится красная строка: `Syntax Error: Missing THEN in conditional branch`.
3. Покажите вызов контекстного меню Error Lens: копирование кода ошибки в буфер обмена.
