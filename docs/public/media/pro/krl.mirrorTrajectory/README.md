# 6D зеркалирование траектории движения манипулятора относительно плоскостей XY, XZ, YZ

> **Категория:** `PRO` | **ID команды:** `krl.mirrorTrajectory` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.mirrorTrajectory`

---

## 🎯 Инженерная задача и ценность
Экономия до 80% времени при пусконаладке симметричных ячеек (левая и правая сторона кузова автомобиля, симметричная сварка/склейка).

## ⚙️ Принцип работы
Математически пересчитывает координаты X, Y, Z и углы Эйлера A, B, C для всех точек в выбранном блоке с корректным пересчетом ориентационных кватернионов и инверсией битов Turn (T), предотвращая скручивание кабельного жгута робота.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/welding_process.dat`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/welding_process.dat` и выделите точки шва левой детали.
2. Вызовите команду `KRL: Зеркалировать траекторию движения (6D Mirroring)`.
3. Выберите плоскость симметрии (например, `XZ Plane — Right/Left Symmetry`).
4. Плагин пересчитывает координаты Y, инвертирует углы A и C и генерирует точки для правой детали `P_MIR_1..N`.
