# Аудит автора строки и временной метки с SmartPAD (GitLens Line Blame)

> **Категория:** `PRO` | **ID команды:** `krl.showLineBlameDetails` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.showLineBlameDetails`

---

## 🎯 Инженерная задача и ценность
Мгновенное понимание контекста каждой строки кода прямо во время редактирования.

## ⚙️ Принцип работы
Отображает ненавязчивую полупрозрачную аннотацию в конце текущей строки курсора: автор коммита, время изменения и первое предложение сообщения коммита.

## 📂 Демонстрационный стенд / Файл
- `Любой KRL файл под управлением Git`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Поставьте курсор на строку вызова движения `LIN XP1`.
2. В конце строки появляется бейдж: `Silvestr Liskin, 3 days ago • Touch-up point after tool replacement`.
3. Кликните на аннотацию — открывается карточка с полным хешем коммита и ссылкой на diff.
