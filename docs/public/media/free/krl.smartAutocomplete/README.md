# Умное автодополнение KSS (957 системных переменных, 116 функций)

> **Категория:** `FREE` | **ID команды:** `krl.smartAutocomplete` | **Горячие клавиши:** `Ctrl+Space`

---

##  Инженерная задача и ценность
Ускорение написания программ в 3–5 раз и исключение опечаток в именах системных переменных контроллера.

##  Принцип работы
Включает базу знаний по всем системным переменным (`$OV_PRO`, `$VEL_ACT`, `$POS_ACT`, `$IN`, `$OUT`, `$FLAG`), функциям ядра KSS (`STRDECL`, `VARSTATE`, `EXECUTE`) с полной подсказкой аргументов и типов прямо при вводе символов.

##  Демонстрационный стенд / Файл
- `demo-workspace/main.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. В файле `demo-workspace/main.src` на новой строке начните вводить: `$OV_`.
2. Открывается контекстное меню автодополнения с описанием переменной `$OV_PRO` на русском языке.
3. Нажмите Enter — переменная вставляется.
4. Начните вводить `BAS(#` — раскрывается список параметров инициализации кинематики.
