# Защитный барьер от столкновений и верификация рабочих зон ($WORKSPACE)

> **Категория:** `PRO` | **ID команды:** `krl.insertCollisionGuard` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.insertCollisionGuard`

---

##  Инженерная задача и ценность
Предотвращение механических аварий и поломки инструмента при въезде робота в зону смежного оборудования (прессы, сварочные клещи, конвейеры).

##  Принцип работы
Генерирует типовой безопасный блок программных интерлоков: запрос зоны `$OUT[...]`, ожидание разрешения `$IN[...]`, проверка аппаратных зон безопасности `$WORKSPACE[...]` и аварийный сброс скорости при отказе концевика.

##  Демонстрационный стенд / Файл
- `demo-workspace/pick_and_place.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. В `demo-workspace/pick_and_place.src` перед подходом к столу захвата детали вызовите `KRL: Вставить интерлок зоны безопасности (Collision Guard)`.
2. В модальном диалоге введите номер зоны безопасности (например, `Zone 3`).
3. Вставляется промышленный защитный блок с проверкой сигналов подтверждения и обработкой таймаута.
