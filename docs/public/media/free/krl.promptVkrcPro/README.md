## 🎯 Инженерная задача и ценность
Быстрый доступ к меню специальных команд для автомобильных комплексов Volkswagen Group.

## ⚙️ Принцип работы
Открывает QuickPick меню команд VASS 26: проверка фольг, аудит макрошагов и конвертация.

## 📂 Демонстрационный стенд / Файл
- `Бэкап VKRC`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Действия контроллера Volkswagen KUKA (VKRC)'.
2. Выберите необходимое действие из автомобильного меню.
