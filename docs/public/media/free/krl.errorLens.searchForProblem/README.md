## 🎯 Инженерная задача и ценность
Мгновенный переход к документации и проверенным решениям конкретной ошибки KSS.

## ⚙️ Принцип работы
Открывает страницу базы знаний Liskin Labs с пошаговыми инструкциями по устранению данной ошибки.

## 📂 Демонстрационный стенд / Файл
- `Строка с ошибкой`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'Error Lens: Найти решение ошибки'.
2. В браузере открывается готовая статья с решением проблемы.
