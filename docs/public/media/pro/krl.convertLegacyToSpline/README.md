# 1-Click конвертер устаревших PTP/LIN/CIRC в современные сплайны KSS 8.3–8.7

> **Категория:** `PRO` | **ID команды:** `krl.convertLegacyToSpline` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.convertLegacyToSpline`

---

##  Инженерная задача и ценность
Модернизация старых программ роботов (KRC2) под современные высокоскоростные сплайновые контроллеры KRC4/KRC5 с более плавным ходом и снижением вибраций.

##  Принцип работы
Преобразует блоки движения старого формата в компактные сплайновые блоки `SPLINE ... ENDSPLINE` с сохранением всех промежуточных точек, параметров динамики и переходом на современные типы `SLIN`, `SCIRC`, `SPL`.

##  Демонстрационный стенд / Файл
- `demo-workspace/motion_and_splines.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Выделите цепочку старых команд LIN / CIRC в `demo-workspace/motion_and_splines.src`.
2. Вызовите `KRL: Конвертировать выделенные движения в блок SPLINE KSS 8.3+`.
3. Код мгновенно заменяется на структурированный сплайновый сегмент с идеальным выравниванием отступов.
4. Покажите отсутствие синтаксических ошибок в панели Problems.
