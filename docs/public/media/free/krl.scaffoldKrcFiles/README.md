# Инициализация чистой структуры KRC-проекта (`KRC/R1/Program`)

> **Категория:** `FREE` | **ID команды:** `krl.scaffoldKrcFiles` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.scaffoldKrcFiles`

---

##  Инженерная задача и ценность
Быстрое развертывание нового робототехнического проекта с нуля с корректной Clean-Room иерархией папок.

##  Принцип работы
Создает структуру папок `KRC/R1/Program` и генерирует минимальный стартовый шаблон пользовательского модуля (`module1.src` и `module1.dat`) без сторонних системных файлов контроллера.

##  Демонстрационный стенд / Файл
- `Пустая рабочая папка проекта`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. В пустой папке вызовите `krl.scaffoldKrcFiles`.
2. В проводнике мгновенно разворачивается чистая заготовка каталога `KRC/R1/Program` со стартовым модулем `.src`/`.dat`.

##  Рекомендуемый визуальный формат
- **Формат:** Анимированный GIF (8 сек) + Скриншот структуры (PNG)
- **Рекомендуемые целевые файлы в эту папку:**
  - `scaffold_krc_demo.gif`
  - `scaffold_krc_screen.png`
