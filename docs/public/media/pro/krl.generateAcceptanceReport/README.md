# Автоматический протокол приёмки ячейки заказчиком (Acceptance Protocol)

> **Категория:** `PRO / Enterprise` | **ID команды:** `krl.generateAcceptanceReport` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.generateAcceptanceReport`

---

## 🎯 Инженерная задача и ценность
Генерация официального акта приёмки роботизированного комплекса для интеграторов, заводов-производителей и OEM-аудиторов с фирменной шапкой.

## ⚙️ Принцип работы
Извлекает серийные номера роботов, версии KSS, контрольные суммы бэкапов, статистику траекторий и подтверждения тестов безопасности. Формирует строгий официальный документ приёмки (Sign-off) с полями для подписи ответственного инженера.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/welding_process.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите `Ctrl+Shift+P` -> `KRL: Сформировать официальный протокол приёмки ячейки (Acceptance Protocol)`.
2. В модальном окне выберите профиль OEM-стандарта (Volkswagen VASS, BMW, Стандарт предприятия).
3. Открывается сформированный протокол приёмки с паспортными данными ячейки, таблицей задействованных сигналов и блоком подписей.
4. Продемонстрируйте превью печати (Print Preview) и экспорт чистого PDF-документа.
