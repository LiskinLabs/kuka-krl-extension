# Очистка мусорных метаданных WorkVisual и временных файлов (.gitkeep, .bak)

> **Категория:** `FREE` | **ID команды:** `krl.cleanGitMetadata` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.cleanGitMetadata`

---

## 🎯 Инженерная задача и ценность
Подготовка проекта к коммиту в Git: удаление временных бинарных логов, резервных копий и системного мусора WorkVisual, загрязняющего репозиторий.

## ⚙️ Принцип работы
Рекурсивно сканирует каталоги проекта, находит файлы `*.bak`, `*.~*`, `Thumbs.db`, пустые временные каталоги и предлагает безопасно очистить их в один клик.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/git_clean_demo.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. В дереве проекта вызовите `KRL: Очистка Git-метаданных WorkVisual`.
2. Плагин сканирует воркспейс и отображает список найденных временных файлов.
3. Нажмите `Очистить` — репозиторий становится чистым и готовым к коммиту без лишнего мусора.
