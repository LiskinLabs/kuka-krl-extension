# Безопасное автоисправление кода с интерактивным Diff-ревью

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.fixAllSafeIssuesInFile` | **Исправить все безопасные ошибки KRL в файле (с Diff Review)** | *Fix All Safe KRL Issues in File (with Diff Review)* |
| `krl.review.accept` | **✓ Принять изменение** | *Accept Change* |
| `krl.review.acceptAll` | **✓✓ Принять все изменения во всех документах** | *Accept All Changes in All Files* |
| `krl.review.reject` | **✕ Отклонить изменение** | *Reject Change* |
| `krl.review.rejectAll` | **✕✕ Отклонить все изменения во всех документах** | *Reject All Changes in All Files* |

## 🎯 Цель демонстрации и визуальный фокус
Инженерная безопасность: код робота никогда не перезаписывается вслепую, только через наглядный Diff-контроль.

## 📂 Демонстрационный файл / Окружение
- `demo-workspace/diagnostics_demo.src`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть `demo-workspace/diagnostics_demo.src` с предупреждениями линтера.
2. Вызвать `KRL: Исправить все безопасные ошибки KRL в файле (с Diff Review)`.
3. Открывается сплит-окно Diff View (слева оригинал, справа исправленная версия): исправление регистра `def -> DEF`, пробелов вокруг операторов, балансировка скобок.
4. В верхней панели появляются кнопки: `✓ Принять`, `✓✓ Принять всё`, `✕ Отклонить`.
5. Нажать `✓ Принять` или `✓✓ Принять всё` -> файл сохраняется с идеальным кодом.
