# KUKA KRL Professional — Полная Вики и Энциклопедия Функционала (v1.8.5 Pro Hub)

Добро пожаловать в интерактивный технический справочник **KUKA KRL Professional Extension** для VS Code.

Наше расширение — это специализированная среда разработки и статический анализатор промышленного класса, созданный инженерами-робототехниками для программирования промышленных роботов KUKA (KSS 8.3 / 8.5 / 8.6 / 8.7).

Ниже приведен подробнейший разбор всех **26 ключевых функций** расширения (15 бесплатных базовых и 11 премиальных промышленных инструментов), их практическая ценность на объекте, комбинации клавиш и видеодемонстрации.

---

## 🟢 Часть 1. Community & Core Features (Бесплатный базовый функционал)

Базовый набор функций доступен бесплатно и кардинально превосходит стандартные редакторские плагины.

### 1. Синтаксическая подсветка KRL (Syntax Highlighting)

* **Для чего нужна:** Обычные текстовые редакторы отображают файлы `.src`, `.dat` и `.sub` как монотонный серый текст. Расширение выполняет полный контекстный парсинг синтаксиса KRL и подсвечивает ключевые слова, типы данных (`INT`, `REAL`, `BOOL`, `E6POS`), системные переменные (`$POS_ACT`, `$VEL.CP`), операторы и структурные FOLD-блоки KUKA WorkVisual.
* **Практическая польза:** Ошибки в опечатках и незакрытых кавычках видна мгновенно, снижая нагрузку на глаза инженера в условиях выездных пусконаладочных работ в цеху.

### 2. Набор эксклюзивных тем KUKA (6 KUKA Themes)

* **Для чего нужна:** Коллекция из 6 контрастных тем оформления, адаптированных для работы на промышленных ноутбуках при ярком цеховом освещении и на экранах SmartPAD:
  1. **Industrial Dark** (фирменный стиль KUKA с промышленным оранжевым акцентом `#FF6600`)
  2. **WorkVisual Dark** (темная тема в стиле KUKA WorkVisual)
  3. **WorkVisual Light** (светлая тема для работы на улице и в светлых лабораториях)
  4. **Midnight OLED** (глубокий черный фон для экономии батареи ноутбука)
  5. **Blueprint** (инженерный чертежный стиль)
  6. **Industrial Light** (контрастная светлая тема)
* **Как вызывать:** Нажмите `Ctrl + K`, затем `Ctrl + T` и выберите любую из тем KUKA.

### 3. Умное автодополнение (Smart Autocomplete & KSS 8.7)

* **Для чего нужна:** При вводе символа `$` или букв переменных редактор открывает интерактивный список с подсказками по всем 350+ системным переменным KSS 8.7 (`$POS_ACT`, `$VEL_ACT`, `$BASE`, `$TOOL`, `$IN`, `$OUT`, `$MODE_OP`), а также пользовательским переменным из файлов `.dat` и подпрограммам.
* **Практическая польза:** Больше не нужно помнить наизусть точные имена системных структур KUKA или заглядывать в бумажные руководства.

### 4. Мультиязычность (Trilingual NLS Localization — EN / RU / TR)

* **Для чего нужна:** Полная локализация интерфейса расширения, включая всплывающие подсказки (Hover), сообщений об ошибках, меню команд, боковые панели TreeView и дашборд Control Center на три языка: **Русский**, **English** и **Турецкий (Türkçe)**.
* **Практическая польза:** Инженерная команда на международных проектах (например, на автомобильных заводах в Турции, России или Европе) работает в привычной языковой среде. Язык подстраивается автоматически под локаль VS Code.

### 5. Inlay Hints для сигналов ($IN / $OUT / $ANIN / $ANOUT)

* **Для чего нужна:** При работе с физическими входами и выходами робота в коде пишутся обезличенные индексы, например `$IN[1]` или `$OUT[4]`. Функция **Inlay Hints** вставляет виртуальный полупрозрачный текст прямо в редактор рядом с каналом (например, `$IN[1]` `: diPartReady`), извлекая имена сигналов из комментариев и `.dat` файлов.
* **Практическая польза:** Инженер видит назначение датчиков и клапанов прямо в коде, не открывая таблицу сигналов и не меняя исходный файл.
* **Демонстрация работы:**

### 6. Подсказки при наведении (Hover Info & Read/Write Status)

* **Для чего нужна:** При наведении курсора мыши на любую переменную или системный параметр (например, `$VEL.CP`, `$POS_ACT`, `$AXIS_ACT`) появляется всплывающая карточка с официальным описанием KSS, типом данных, допустимым диапазоном значений и правами доступа (**Read-Only / Read-Write**).
* **Практическая польза:** Исключает попытки записи в переменные только для чтения (например, `$POS_ACT`) до загрузки на шкаф KRC.

### 7. Кросс-файловая навигация (.src ↔ .dat Go-to-Definition)

* **For what it's needed / Для чего нужна:** В структуре KRL логика движения находится в файле `.src`, а объявления координат точек `E6POS`, инструмента `$TOOL` и фреймов `$BASE` — в сопряжённом файле `.dat`. Функция навигации по нажатию `F12` или `Ctrl + Click` мгновенно переносит курсор от вызова точки в `.src` к её точному месту объявления в `.dat`.

### 13. Очистка неиспользуемых переменных (Unused Variable Cleaner)

* **Для чего нужна:** Команда `KRL: Clean Up Unused Variables` автоматически сканирует `.dat` файлы и находит объявленные переменные `DECL`, которые нигде не вызываются в алгоритме `.src`. Позволяет быстро очистить `.dat` файл без повреждения структуры FOLD метаданных.

---

### 14. Очиститель Git-метаданных WorkVisual (Git Metadata Cleaner)

* **Для чего нужна:** KUKA WorkVisual при каждом сохранении замусоривает служебные заголовки `&ACCESS RVP`, `&REL 1`, `&PARAM TEMPLATE`, что ломает диффы в системах контроля версий Git. Команда `KRL: Clean KUKA Git Metadata` аккуратно срезает переменный мусор, оставляя только чистую логику KRL.
* **Демонстрация работы:**

![Git Metadata Cleaner Demo](/media/git_metadata_cleaner.gif)

### 17. Интерактивная обратная связь и чат в VS Code (Telegram Support Panel)

---

### 18. Автономная Консоль Администратора Поддержки (`KukaAdminHelpdesk.exe`)

* **Для чего нужна:** Отдельное нативное Windows-приложение диспетчера для руководителей отделов автоматизации. Показывает онлайн-статус инженерных станций в цеху (🟢 ONLINE / 🟡 IDLE / 🔴 OFFLINE) и позволяет осуществлять централизованную поддержку пусконаладчиков.

---

### 19. KRC Backup Diff & Point Delta Inspector

* **Для чего нужна:** Выбирает ZIP-архив бэкапа SmartPAD с робота (KRC4/KRC5) и сравнивает его с локальным проектом. Автоматически парсит координаты `E6POS`/`E6AXIS` и рассчитывает физическую дельту смещения точек по осям ($\Delta X, \Delta Y, \Delta Z, \Delta A, \Delta B, \Delta C$).
* **Практическая польза:** Предотвращает столкновения, если оператор в цеху подправил точку со SmartPAD вручную, а инженер на ноутбуке заливает старый проект.
* **Демонстрация работы:**

![KRC Backup Diff Demo](/media/krc_backup_diff.gif)

### 20. Интерактивный генератор траекторий и сниппетов движения

* **Для чего нужна:** Двухколоночный интерфейс для визульного конструирования движений KUKA: `PTP`, `LIN`, `CIRC`, `SPTP`, `SLIN`, `SCIRC` и блоков `SPLINE`. В режиме реального времени строит динамическую векторную SVG-схему траектории TCP с подсветкой векторов осей, промежуточных точек $P_0, XpAux, XpTarget$ и профиля рывка `$SGEAR_JERK`.

Визуализирует условия `IF/THEN/ELSE`, циклы `LOOP`, ветвления `SWITCH/CASE`, таймеры и команды движения. Клик по подпрограмме мгновенно загружает её блок-схему (drill-down). Есть экспорт в SVG.

### 22. EthernetKRL (EKI) Suite & Handler Generator

* **Для чего нужна:** Модуль для работы с сетевым обменом KUKA EthernetKRL. Выполняет валидацию XML-схем взаимодействия с внешними PLC/Vision системами и автоматически генерирует полный KRL-модуль обработки сетевых сокетов (`EKI_Init`, `EKI_Open`, `EKI_Get*`, `EKI_Send*`).

---

### 23. Диагностика промышленной безопасности (Safety & Velocity Check)

* **Для чего нужна:** Автоматический инспектор безопасности (`KRL: Run Safety Check`). Сканирует код на:
  1. Превышение безопасной скоростиCommissioning (`$VEL.CP > 3.0 m/s`).
  2. Запуск команд движения без предварительной инициализации активного инструмента `$TOOL` и базы `$BASE`.
  3. Наличие невидимых символов кириллицы в исполняемых строках, выбывающих контроллер KRC в фатальную ошибку.

---

### 24. AI-Supportive Domain Context Tools (`@kuka /get-io-matrix`, `@kuka /check-safety`)

* **Для чего нужна:** Инструменты интеграции со встроенным ИИ (Google Antigravity IDE / GitHub Copilot). Передают точный контекст KSS 8.7, сигнальную матрицу I/O в JSON и результаты проверок безопасности в prompt ИИ, устраняя галлюцинации нейросетей при написании KRL кода.

---

### 25. 3-Point Frame Calculator (Калькулятор баз и инструментов)

* **Для чего нужна:** Геометрический 3D-калькулятор системы координат (`krl.showCalculator`). Принимает координаты 3 опорных точек (Origin, X-Axis, XY-Plane) и мгновенно вычисляет матрицу трансформации и углы Эйлера (A, B, C) для настройки `BASE_DATA[x]`.

---

### 26. Генератор отчётов приёмки (Quality Acceptance Report)

* **Для чего нужна:** Выгружает структурированный HTML/JSON отчёт о качестве кода и соблюдении стандартов безопасности проекта. Идеально подходит для сдачи объекта техническому заказчику.
