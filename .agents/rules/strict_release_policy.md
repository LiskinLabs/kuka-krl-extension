# Strict Release & Publishing Policy Directive

## 🛑 MANDATORY CORE DIRECTIVE: ZERO UNAUTHORIZED RELEASES
1. **Категорически запрещено публиковать релизы (`vsce publish`, `gh release create`, создание/пуш релизных тегов `git tag v*`, загрузка на Open VSX или VS Code Marketplace) БЕЗ ЯВНОГО, ПРЯМОГО СОГЛАСИЯ СИЛЬВЕСТРА.**
2. Автоматическое одобрение промежуточных планов системой или UI (`review policy`) **НЕ** является разрешением на публикацию релиза в сеть или маркетплейсы.
3. Перед любой публикацией новой версии расширения агент **ОБЯЗАН** явно спросить пользователя в чате:  
   *«Все тесты пройдены, пакет vX.Y.Z собран локально. Вы подтверждаете публикацию релиза на Marketplace и GitHub?»* — и ждать явного ответа: «Да, публикуй».
4. До явной команды пользователя агент может выполнять **ТОЛЬКО** локальную разработку: написание кода, локальную компиляцию, запуск тестов (`npm test`) и локальную упаковку `.vsix` (`vsce package`) для проверки.
