# Генератор сплайновых блоков с параметрами приближения (SLIN, SCIRC, SPL)

> **Категория:** `PRO` | **ID команды:** `krl.insertSplineBlock` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.insertSplineBlock`

---

## 🎯 Инженерная задача и ценность
Быстрая вставка корректно параметризованного сплайнового движения без необходимости вручную помнить сложный синтаксис KSS 8.6/8.7.

## ⚙️ Принцип работы
Генерирует готовый шаблон сплайна с секцией инициализации скорости, ускорения, рывка (Jerk) и определением контрольных сегментов с критериями сглаживания.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/motion_and_splines.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Поставьте курсор в тело программы.
2. Вызовите `KRL: Вставить сплайновый блок движения`.
3. Вставляется готовый синтаксический блок `SPLINE WITH ...` с плейсхолдерами Tab-навигации.
4. Заполните имя целевой точки нажатием клавиши Tab.
