# Промышленный аудит безопасности и пре-релизный отчёт качества

> **Категория:** `PRO` | **ID команды:** `krl.generateReport` | **Горячие клавиши:** `Ctrl+Alt+D`

---

##  Инженерная задача и ценность
Полный статический аудит проекта KRL перед заливкой в контроллер: выявление падений Vorlaufstopp, неинициализированных $TOOL/$BASE, дедлоков и превышений рабочей зоны.

##  Принцип работы
Сканирует всю рабочую область или выбранную папку, агрегирует нарушения по категориям (Критический риск, Дедлок, Производительность, Стиль), рассчитывает индекс качества Health Score (0-100%) и формирует интерактивный отчет с возможностью экспорта в PDF и Markdown.

##  Демонстрационный стенд / Файл
- `demo-workspace/diagnostics_demo.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/diagnostics_demo.src` или весь проект `demo-workspace`.
2. Нажмите `Ctrl+Alt+D` или вызовите `KRL: Сформировать промышленный отчёт аудита проекта`.
3. Появится статус-бар сканирования AST-деревьев.
4. Откроется сгенерированный отчёт: круговая диаграмма Health Score, матрица рисков, перечень проблем с кнопками быстрого перехода.
5. Продемонстрируйте фильтрацию по критичности (Critical Errors Only) и кнопку экспорта в PDF/Markdown.
