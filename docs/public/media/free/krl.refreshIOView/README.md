# Обновить дерево сигналов ввода/вывода (I/O View)

> **Категория:** `FREE` | **ID команды:** `krl.refreshIOView` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Принудительная переиндексация карты сигналов $IN/$OUT в боковой панели.

## ⚙️ Принцип работы
Заново сканирует файлы $config.dat и модули проекта, обновляя дерево дискретных сигналов.

## 📂 Демонстрационный стенд / Файл
- `Панель I/O Signals`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Нажмите иконку обновления в панели I/O Signals.
2. Дерево сигналов обновлено с учетом последних правок.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот панели сигналов
- **Рекомендуемые целевые файлы в эту папку:**
