# ИИ-ассистент KUKA AI Copilot и прямая поддержка разработчиков

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.sendSelectionToChat` | **Отправить выделенный фрагмент в KUKA AI Copilot** | *Send Selection to KUKA AI Copilot* |
| `krl.openTelegramChat` | **Прямой чат с инженером-разработчиком** | *Direct Engineering Support* |
| `krl.sendToDeveloper` | **Отправить разработчику…** | *Send to Developer…* |
| `krl.checkSupportStatus` | **Проверить статус шлюза поддержки** | *Check Support Gateway Status* |

## 🎯 Цель демонстрации и визуальный фокус
Связка искусственного интеллекта и прямого контакта с создателями расширения.

## 📂 Демонстрационный файл / Окружение
- `Любой KRL код`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Выделить сложный или закомментированный блок кода -> `KRL: Отправить выделенный фрагмент в KUKA AI Copilot`.
2. Открывается панель чата ИИ, где ассистент мгновенно объясняет назначение блока и предлагает оптимизацию.
3. Нажать `KRL: Прямой чат с инженером-разработчиком` -> переход в официальный канал поддержки Liskin Labs для решения нестандартных цеховых задач.
