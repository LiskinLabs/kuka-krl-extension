# Просмотр изображения модели робота KUKA (WorkVisual)

> **Категория:** `FREE` | **ID команды:** `krl.viewRobotImage` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Визуальная идентификация физического манипулятора ячейки (паспортная модель, грузоподъемность, досягаемость).

## ⚙️ Принцип работы
Извлекает имя кинематической модели из файлов бэкапа и отображает официальное фото/рендер соответствующего манипулятора (Quantec, Cybertech, Titan, Iiwa).

## 📂 Демонстрационный стенд / Файл
- `Любой бэкап робота`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Просмотр изображения модели робота'.
2. В редакторе открывается карточка робота с фото и техническими характеристиками.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот карточки робота с фото
- **Рекомендуемые целевые файлы в эту папку:**
  - `view_robot_image_screen.png`

---
*Примечание: Сохраняйте созданные скриншоты, GIF-анимации и видео прямо в эту папку. Они автоматически подхватываются документацией и витриной маркетплейса.*
