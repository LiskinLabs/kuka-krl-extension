# Интерактивная блок-схема KRL (Control Flow Graph)

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.showFlowchart` | **Интерактивная блок-схема KRL (Flowchart)** | *Show Control Flow Graph (Flowchart)* |

## 🎯 Цель демонстрации и визуальный фокус
Визуализация сложной логики программы для согласования с технологами и быстрого отлаживания алгоритмов.

## 📂 Демонстрационный файл / Окружение
- `demo-workspace/flowchart_demo.src`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть `demo-workspace/flowchart_demo.src`.
2. Вызвать `KRL: Интерактивная блок-схема KRL (Flowchart)` (krl.showFlowchart).
3. Рядом с кодом открывается интерактивный граф Mermaid/SVG: ветвления IF-THEN-ELSE, циклы LOOP/FOR/WHILE, вызовы подпрограмм.
4. Показать клик по узлу блок-схемы -> редактор мгновенно скроллится к соответствующей строке кода KRL.
