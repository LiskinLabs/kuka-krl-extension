# Глубокая очистка неиспользуемых переменных, массивов и структур в .dat

> **Категория:** `PRO` | **ID команды:** `krl.cleanupUnusedVariables` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.cleanupUnusedVariables`

---

## 🎯 Инженерная задача и ценность
Освобождение оперативной памяти контроллера KRC (RAM) и удаление мусорных точек, оставшихся после старых ревизий техпроцесса.

## ⚙️ Принцип работы
Строит карту перекрестных ссылок (Symbol Cross-Reference Table). Находит все переменные в `.dat` файле, которые ни разу не читаются и не модифицируются в `.src` файлах проекта, и безопасно удаляет их, сохраняя структуру нужных данных.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/dead_code_demo.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/dead_code_demo.src` и парный `.dat` файл.
2. Обратите внимание на серые приглушенные строки неиспользуемых переменных.
3. Вызовите `KRL: Удалить неиспользуемые переменные и мертвый код`.
4. Плагин выводит список найденных сиротских переменных с возможностью выбора.
5. Подтвердите удаление — `.dat` файл очищен, память контроллера оптимизирована.
