# Error Lens: Скопировать текст ошибки в буфер обмена

> **Категория:** `FREE` | **ID команды:** `krl.errorLens.copyProblemMessage` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Мгновенное копирование формулировки ошибки для составления отчета или отправки коллегам.

## ⚙️ Принцип работы
Копирует диагностическое сообщение текущей строки в системный буфер обмена.

## 📂 Демонстрационный стенд / Файл
- `Строка с ошибкой`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Поставьте курсор на строку с ошибкой и вызовите команду.
2. Текст ошибки скопирован в буфер обмена.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** Скриншот всплывающего уведомления
- **Рекомендуемые целевые файлы в эту папку:**
  - `error_lens_copy_msg_screen.png`
