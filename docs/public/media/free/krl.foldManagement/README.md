# Управление структурой FOLD: свернуть/развернуть, вставить FOLD-регион, unwrap

> **Категория:** `FREE` | **ID команды:** `krl.foldManagement` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.insertFold / krl.unwrapFold`

---

## 🎯 Инженерная задача и ценность
Работа с фирменными скрытыми блоками KUKA (FOLD/ENDFOLD), скрывающими громоздкие технические параметры движений и масок SmartPAD.

## ⚙️ Принцип работы
Позволяет в один клик свернуть или развернуть все фолды в файле, создать новый защищенный блок `;FOLD MyRoutine ... ;ENDFOLD` или полностью очистить код от фолд-оболочек для чистого чтения логики.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/main.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/main.src`.
2. Нажмите кнопку в панели инструментов `Свернуть все FOLD`. Весь файл превращается в компактные аккуратные строки.
3. Выделите участок логики и вызовите `KRL: Вставить FOLD-регион`. Введите имя `GRIPPER_SEQUENCE`.
4. Код автоматически обрамляется стандартными тегами `;FOLD` и `;ENDFOLD`.
