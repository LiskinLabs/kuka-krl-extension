# Проводник робопарка предприятия (Fleet Robot Explorer)

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.fleetExplorer.refresh` | **Обновить KUKA Fleet Robot Explorer** | *Refresh KUKA Fleet Robot Explorer* |

## 🎯 Цель демонстрации и визуальный фокус
Корпоративное управление парком из десятков промышленных роботов в одном окне.

## 📂 Демонстрационный файл / Окружение
- `Боковая панель KUKA Fleet Explorer`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть боковую панель KUKA Fleet Explorer.
2. Нажать кнопку обновления или команду `KRL: Обновить KUKA Fleet Robot Explorer`.
3. Показать древовидную структуру завода: Цех -> Роботизированная ячейка -> Робот (с серийным номером, версией KSS и статусом бэкапа).

- **Формат:** Скриншот или короткий GIF (4-5 сек)

  - `fleet_explorer_tree.png`
  - `fleet_refresh.gif`

> *Примечание: После создания скриншота, GIF или видео сохраняйте готовые файлы прямо в эту папку. Они будут автоматически синхронизироваться с сайтом документации и витриной маркетплейса.*
