# Формирование карты наладки ячейки (Setup Sheet / Rüstplan)

> **Категория:** `FREE` | **ID команды:** `krl.generateSetupSheet` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.generateSetupSheet`

---

## 🎯 Инженерная задача и ценность
Документация для операторов и наладчиков смены: перечень необходимой оснастки, калибровок инструментов и баз перед запуском программы.

## ⚙️ Принцип работы
Сканирует проект, извлекает все задействованные инструменты `$TOOL`, базы деталей `$BASE`, внешние оси и список входных/выходных сигналов и формирует читаемый отчет на бланке наладки.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/cell.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/cell.src`.
2. Вызовите `KRL: Сформировать карту наладки ячейки (Setup Sheet)`.
3. Открывается аккуратный документ Rüstplan с таблицей оснастки, номерами инструментов и требованиями к исходному положению ячейки.
