# Integración de IA con Model Context Protocol (MCP)

Conexión de herramientas avanzadas de IA a la telemetría del robot y al diagnóstico estático de proyectos KRL.

---

## Descripción general

La extensión KUKA KRL incluye un **servidor puente local MCP** en `127.0.0.1` compatible con **Cursor, Google Antigravity, Claude Code y Windsurf**, permitiendo consultar telemetría en vivo (`krl_live_telemetry`), diagnóstico estático (`krl_workspace_diagnostics`) y especificaciones de variables KSS en tiempo real.
