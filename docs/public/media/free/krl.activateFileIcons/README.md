# Брендированные иконки KUKA для файлов .src, .dat, .sub, .kfd в проводнике

> **Категория:** `FREE` | **ID команды:** `krl.activateFileIcons` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.activateFileIcons`

---

##  Инженерная задача и ценность
Визуальный комфорт и мгновенная ориентация в проводнике файлов проекта робота.

##  Принцип работы
Активирует фирменную оранжево-черную тему иконок: уникальные SVG-значки для программ `.src`, файлов данных `.dat`, фоновых submit-интерпретаторов `.sub` и описаний FOLD `.kfd`.

##  Демонстрационный стенд / Файл
- `Проводник VS Code с папкой KRL`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите `KRL: Включить фирменные иконки файлов KRL`.
2. В проводнике слева у всех файлов `.src`, `.dat`, `.sub` загораются стильные контрастные промышленные иконки KUKA.

##  Рекомендуемый визуальный формат
- **Формат:** Красивый скриншот проводника файлов (PNG 1920x1080)
- **Рекомендуемые целевые файлы в эту папку:**
  - `file_icons_screen.png`
