# Подсказки сигналов оборудования Inlay Hints

<span class="badge pro">Community & Pro Функция</span>

Мгновенная видимость физического назначения входов и выходов оборудования без переключения файлов.

![Inlay Hints Demo](/media/inlay_hints.gif)

## Как это работает
Расширение вставляет полупрозрачные подсказки имен сигналов (например, `$IN[1]` `: diPartReady`) прямо в текст редактора.

* **Настройка**: Функция включается и отключается в параметрах VS Code (`krl.inlayHints.enabled`).
