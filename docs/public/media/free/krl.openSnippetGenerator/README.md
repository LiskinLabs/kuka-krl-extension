# Инженерный генератор сниппетов, заготовок движения и циклов обработки

> **Категория:** `FREE` | **ID команды:** `krl.openSnippetGenerator` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.openSnippetGenerator`

---

##  Инженерная задача и ценность
Быстрое создание типовых программных шаблонов: циклов паллетирования, опроса датчиков, подпрограмм смены инструмента и обработки прерываний.

##  Принцип работы
Предоставляет интерактивный визуальный мастер выбора шаблона с настройкой параметров (количество слоев, число деталей, номера входных сигналов) и вставляет синтаксически чистый код прямо в активный редактор.

##  Демонстрационный стенд / Файл
- `Новый пустой файл `.src``

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. В пустом файле вызовите `KRL: Открыть генератор сниппетов и траекторий`.
2. Выберите шаблон: `Паллетирование (Palletizing 3x3x3)`.
3. Задайте параметры сетки и нажмите `Вставить в редактор`.
4. В файл вставляется полнофункциональный цикл с тремя вложенными циклами FOR и расчетом смещений точек.
