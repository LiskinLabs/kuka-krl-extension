# Анализ неиспользуемого кода (Dead-Code Analysis)

<span class="badge pro">Функция Pro</span>

Гарантируйте соответствие кодовой базы строгим стандартам мировых автопроизводителей (VASS, BMW, Stellantis). Промышленные стандарты требуют чистого и оптимизированного кода без мусорных и неиспользуемых переменных.

![Демонстрация анализа неиспользуемого кода](/media/kuka_commands.gif)

## Как это работает

KUKA KRL Professional индексирует все рабочее пространство (все файлы `.src`, `.dat` и `.sub`), выстраивая полный граф зависимостей:

* **Неиспользуемые локальные переменные**: Выявляет объявленные, но нигде не задействованные переменные внутри подпрограмм.
* **Неиспользуемые глобальные процедуры**: Находит подпрограммы `GLOBAL DEF`, которые объявлены, но никогда не вызываются в проекте.
* **Неиспользуемые сигналы I/O**: Подсвечивает сигналы ввода/вывода, объявленные в `.dat`, но ни разу не прочитанные и не записанные.

## Отчеты о качестве кода

Формируйте структурированные отчеты о состоянии кода для демонстрации заказчику или ведущему инженеру. Запустите команду `KRL: Generate Analysis Report` из палитры команд (`Ctrl+Shift+P`).
