# Проверить статус виртуального контроллера KUKA

> **Категория:** `FREE` | **ID команды:** `krl.checkVirtualControllerStatus` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Быстрая диагностика доступности и сетевого отклика эмулятора KSS / OfficePC перед отправкой кода.

## ⚙️ Принцип работы
Пингует настроенный сетевой порт виртуального контроллера и выводит статус доступности в уведомлении.

## 📂 Демонстрационный стенд / Файл
- `Виртуальный контроллер в локальной сети`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Проверить статус виртуального контроллера'.
2. Получите статусное сообщение о готовности эмулятора к работе.

- **Формат:** Скриншот всплывающего уведомления
