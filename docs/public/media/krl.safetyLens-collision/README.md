# Контроль безопасности (Safety Lens) и CollisionGuard

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.safetyLens.toggle` | **Переключить KRL Inline Safety Lens** | *Toggle KRL Inline Safety Lens* |
| `krl.insertCollisionGuard` | **Вставить защиту от коллизий (CollisionGuard)** | *Insert CollisionGuard / Torque Envelope* |

## 🎯 Цель демонстрации и визуальный фокус
Предотвращение аварий и повреждения дорогостоящего манипулятора прямо на этапе редактирования кода.

## 📂 Демонстрационный файл / Окружение
- `demo-workspace/motion_and_splines.src`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Открыть `demo-workspace/motion_and_splines.src`.
2. Включить `KRL: Переключить KRL Inline Safety Lens` -> в строках кода появляются предупреждающие бейджи: превышение скорости с инструментом, опасные зоны разгона.
3. Выделить потенциально опасный участок траектории (например, вход в зону пресса) -> `KRL: Вставить защиту от коллизий (CollisionGuard)`.
4. Вставляется защитная оболочка с контролем моментов осей `$TORQUE_MONITORING`.
