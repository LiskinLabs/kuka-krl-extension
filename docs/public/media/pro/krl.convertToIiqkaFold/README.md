# Конвертировать в iiQKA Motion Fold (KSS -> iiQKA)

> **Категория:** `PRO` | **ID команды:** `krl.convertToIiqkaFold` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Модернизация программ для новейших контроллеров KUKA iiQKA и роботизированных операционных систем нового поколения.

## ⚙️ Принцип работы
Преобразует классические Inline-формы KSS 8.x в синтаксические конструкции нового формата iiQKA Motion Folds.

## 📂 Демонстрационный стенд / Файл
- `Программа KSS 8.3/8.6/8.7`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Выделите блок движения.
2. Нажмите 'KRL: Конвертировать в iiQKA Motion Fold'.
3. Код обновляется до современного стандарта iiQKA.
