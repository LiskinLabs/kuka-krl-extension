# Динамический симулятор кинематики, зон сингулярности и перегрузок осей

> **Категория:** `PRO` | **ID команды:** `krl.runDynamicAnalysis` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.runDynamicAnalysis`

---

## 🎯 Инженерная задача и ценность
Предотвращение аварийной остановки робота из-за попадания в кинематическую сингулярность запястья (Axis 5 = 0°) или превышения скорости осей.

## ⚙️ Принцип работы
Просчитывает решение обратной кинематики для цепочки точек программы с учетом каталожных параметров конкретной модели робота KUKA (183 модели в базе). Детектирует околосингулярные зоны запястья и предупреждает о риске мгновенного разворота 4 и 6 осей.

## 📂 Демонстрационный стенд / Файл
- `demo-workspace/motion_and_splines.src`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/motion_and_splines.src`.
2. Вызовите `KRL: Запустить динамический анализ траектории и сингулярностей`.
3. Открывается отчет кинематического симулятора: графики скоростей осей A1-A6 и выделенные опасные зоны с предупреждением `Wrist Singularity Risk at point XP3`.
