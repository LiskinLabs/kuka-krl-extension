# Выгрузить проект в архив бэкапа KRL (.zip)

> **Категория:** `FREE` | **ID команды:** `krl.exportBackupZip` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Быстрая упаковка активного проекта в стандартный архив бэкапа для загрузки на пульт SmartPAD робота.

## ⚙️ Принцип работы
Собирает папки KRC/R1, System, Steu в валидный ZIP-архив с очисткой мусорных файлов операционной системы.

## 📂 Демонстрационный стенд / Файл
- `Активный проект робота`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите 'KRL: Выгрузить бэкап проекта (.zip)'.
2. Укажите путь сохранения — архив готов к передаче на флешку робота.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** GIF (6 сек) создания архива
- **Рекомендуемые целевые файлы в эту папку:**
  - `export_backup_zip_demo.gif`
  - `export_backup_zip_screen.png`
