# Сравнить две любые ревизии файла (Git Diff)

> **Категория:** `FREE` | **ID команды:** `krl.compareTwoRevisions` | **Горячие клавиши:** `—`

---

## 🎯 Инженерная задача и ценность
Глубокое сравнение текущей программы с версией трехмесячной давности или заводским эталоном.

## ⚙️ Принцип работы
Предоставляет выбор двух коммитов из истории Git и открывает Side-by-Side Monaco Diff.

## 📂 Демонстрационный стенд / Файл
- `Файл с богатой историей коммитов`

## 🎬 Пошаговый сценарий демонстрации (Скрипт записи)
1. Вызовите команду и выберите два коммита для сравнения.
2. Открывается двухпанельное сравнение с подсветкой добавленных и удаленных строк.

## 🎥 Рекомендуемый визуальный формат
- **Формат:** GIF (10 сек) сравнения двух ревизий
- **Рекомендуемые целевые файлы в эту папку:**
  - `compare_two_revisions_demo.gif`
  - `compare_two_revisions_screen.png`
