# Встраиваемые подсказки Inlay Hints с именами сигналов ввода-вывода

> **Категория:** `FREE` | **ID команды:** `krl.inlayHints` | **Горячие клавиши:** `Автоматически в редакторе`

---

##  Инженерная задача и ценность
Чтение кода без необходимости переключаться в `$config.dat`: рядом с номерами сигналов `$OUT[25]` сразу отображается их человекопонятное имя.

##  Принцип работы
Сканирует таблицу сигналов в `$config.dat` и динамически внедряет компактные нередактируемые плашки прямо в строку редактора: `$OUT[25] /* Gripper_Close */ = TRUE`.

##  Демонстрационный стенд / Файл
- `demo-workspace/pick_and_place.src`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. Откройте `demo-workspace/pick_and_place.src`.
2. Обратите внимание на строки присваивания сигналов `$OUT[1] = TRUE`.
3. Рядом с числом `1` отображается аккуратная плашка с именем сигнала `: Gripper_Clamp`.
4. Покажите переключение настройки в `settings.json` (включение/отключение Inlay Hints).
