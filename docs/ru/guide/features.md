# KUKA KRL Professional - Вики (Функции)

Добро пожаловать в официальную документацию по всем функциям расширения **KUKA KRL Professional**.

## 🟢 Community Edition (Бесплатная)

Эти функции доступны абсолютно бесплатно для всех и помогают ускорить стандартную разработку.

### 1. Синтаксическая подсветка
Полный парсинг и раскраска кода файлов `.src` и `.dat` в строгом соответствии со спецификациями KUKA KRC.

### 2. Эксклюзивные темы KUKA
В комплекте три кастомные темные темы, созданные специально для инженеров:
- **Industrial Dark**
- **Midnight OLED** 
- **Blueprint**

### 3. Умное автодополнение
Введите `$`, чтобы мгновенно получить выпадающий список всех системных переменных KUKA, с указанием типов данных и описаний.

### 4. Мультиязычность (EN/RU/TR)
Все расширение, включая всплывающие подсказки и ошибки, полностью переведено на английский, русский и турецкий языки.

### 5. Inlay Hints (Подсказки сигналов)
Виртуальный текст появляется прямо в редакторе рядом с сигналами оборудования (например, `$IN[1]`), показывая их реальные имена (например, `Sensor 1`).

### 6. Всплывающая информация (Hover)
Наведите курсор на любую системную переменную (например, `$VEL.CP`), чтобы получить мгновенный доступ к документации KUKA.

### 7. Навигация между файлами (Go-to-Definition)
Удерживайте `Ctrl` и кликните по переменной в `.src`, чтобы мгновенно перейти к её объявлению в `.dat` файле.

### 8. Глобальный форматтер
Нажмите `Shift + Alt + F` для мгновенного форматирования кода. Автоматически выравнивает знаки `=` в матрицах.

### 9. Визуальный генератор сниппетов
Встроенная панель GUI позволяет визуально конструировать движения PTP/LIN и логику без ввода текста вручную.

## 👑 Industrial Edition (Pro)

Industrial Edition работает как строгий статический анализатор и инспектор безопасности всего вашего рабочего пространства.

### 10. Интерактивный просмотрщик блок-схем
Превращает сложные программы `.src` в наглядные графы (Mermaid SVG). Визуализирует таймеры, движения и сигналы, позволяет проваливаться в подпрограммы по клику.

### 11. Анализ баланса блоков
Больше никакой боли от забытых `ENDIF`. Анализатор мгновенно подчеркнет красным место, где нарушена структура блоков.

### 12. Контроль безопасности (Скорости)
Ввод `$VEL.CP = 5.0` мгновенно вызовет предупреждение. Анализатор проверяет, превышают ли захардкоженные скорости безопасные пределы пусконаладки.

### 13. Проверка инициализации Tool/Base
Попытка запустить команду движения (например, `PTP P1`) без предварительной инициализации активных `$TOOL` и `$BASE` будет пресечена. Предотвращает аварии робота.

### 14. Блокировщик скрытых ошибок (Кириллица)
Компилятор KRC падает без объяснений, если в исполняемом коде есть символы не из ASCII (кириллица). Наш блокировщик ловит эти невидимые ошибки.

### 15. Глобальный анализ "мертвого" кода
Сканирует всю папку. Любые функции `GLOBAL DEF` или переменные, которые нигде не вызываются, будут подсвечены серым цветом для последующего удаления.

### 16. Очистка метаданных WorkVisual
Удаляет мусор, генерируемый WorkVisual (например, `&ACCESS`), в один клик. Делает коммиты в Git чистыми.

### 17. Калькулятор фреймов KUKA
Встроенный 3D геометрический инструмент. Введите координаты 3 точек (Origin, X, XY), и он мгновенно рассчитает правильные углы фрейма (A, B, C) для `BASE_DATA`.

### 18. Отчет о качестве кода
Генерация HTML/JSON отчета по всему проекту. Позволяет мгновенно оценить количество ошибок, предупреждений и процент "мертвого" кода.

### 19. KRC Backup Diff & Inspector точек (v1.8.5)
Сравнение файлов `.src`/`.dat` и покомпонентных дельт координат ($\Delta X, \Delta Y, \Delta Z, \Delta A, \Delta B, \Delta C$) напрямую из `.zip` архивов бэкапов SmartPAD (KRC4/KRC5).

### 20. Схемы траекторий движения и Spline сниппеты (v1.8.5)
Динамические SVG-диаграммы траекторий TCP для `PTP`, `LIN`, `CIRC`, `SPTP`, `SLIN`, `SCIRC` и блоков `SPLINE` с автоматической настройкой векторов осей, точек $P_0, XpAux, XpTarget$ и профиля рывка ($SGEAR\_JERK$).

### 21. EthernetKRL (EKI) XML Suite (v1.8.0)
Валидатор схем EthernetKRL XML и автоматический генератор KRL-модулей обмена данными по TCP/IP.

### 22. KUKA Control Center & AI Context Tools
Центральный панельный хаб управления в один клик и специализированные инструменты интеграции с ИИ-ассистентами (`@kuka /get-io-matrix`, `@kuka /check-safety`).
