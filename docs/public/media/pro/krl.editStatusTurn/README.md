# Визуальный интерактивный редактор битовых масок Status (S) и Turn (T)

> **Категория:** `FREE` | **ID команды:** `krl.editStatusTurn` | **Горячие клавиши:** `Ctrl+Shift+P -> krl.editStatusTurn`

---

##  Инженерная задача и ценность
Устранение неожиданных оборотов осей манипулятора при переходе в точку из-за неправильно выставленных битов Turn.

##  Принцип работы
Декодирует битовые маски Status (0..7) и Turn (0..63) в понятные флаги положения осей (положительный/отрицательный оборот для каждой оси A1..A6) и позволяет менять их через кликабельные чекбоксы.

##  Демонстрационный стенд / Файл
- `demo-workspace/pick_and_place.dat`

##  Пошаговый сценарий демонстрации (Скрипт записи)
1. В файле `.dat` кликните на параметры точки `S 'B010', T 'B101010'`.
2. Вызовите `KRL: Открыть визуальный редактор Status и Turn`.
3. Открывается окно с интерактивными тумблерами для каждой из 6 осей робота.
4. Переключите тумблер оси A4 — результирующая битовая маска автоматически обновляется в коде.
