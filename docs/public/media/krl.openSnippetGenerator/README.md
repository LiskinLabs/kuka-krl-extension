# Генератор сниппетов и типовых алгоритмов KRL

## 📋 Команды в этой группе

| Идентификатор команды (ID) | Название (RU) | Name (EN) |
| :--- | :--- | :--- |
| `krl.openSnippetGenerator` | **Генератор сниппетов и траекторий KRL** | *KRL Snippet & Motion Generator* |

## 🎯 Цель демонстрации и визуальный фокус
Быстрая генерация сложных конструкций без ошибок в синтаксисе прерываний и флагов.

## 📂 Демонстрационный файл / Окружение
- `Любой KRL файл`

## 🎬 Пошаговый сценарий записи (Скрипт действий)
1. Нажать `Ctrl+Shift+P` -> `KRL: Генератор сниппетов и траекторий KRL`.
2. Открывается диалог выбора шаблона: цикл паллетирования, обработка прерываний INTERRUPT, безопасный возврат в домашнюю позицию HOME.
3. Выбрать шаблон, задать базовые параметры -> готовый код вставляется в позицию курсора.
